# 拾光 Luma

拾光（Luma）是一个 macOS 原生照片管理应用，使用 SwiftUI + SQLite 构建，界面与交互对齐系统「照片」，并额外提供网络存储（SMB / WebDAV / 阿里云盘 / 百度网盘）与官方「照片」图库接入。

- 包标识：`com.baymax.luma`
- 最低系统：macOS 14.0
- 技术栈：Swift 5.9（SwiftPM）、SwiftUI、AppKit、Core Image、AVFoundation、SQLite（系统 `libsqlite3`）
- 第三方依赖：无

## 功能

### 图库
- 图库是一个 `.photoslibrary` 包，可放在任意文件夹或外置磁盘；应用不保存固定位置的数据。
- 首次启动没有图库时必须新建或打开一个图库（引导页），之后启动自动打开上次使用的图库。
- 按住 **Option** 启动会先弹出「选取图库」面板（列出当前图库、最近打开、`~/图片` 下的所有 `.photoslibrary`），也可从「文件 › 选取图库…」打开。
- 图库选择器支持新建图库、打开任意位置图库；打开官方「照片」图库时以该图库为准，照片只读解析、拾光自己的数据写在该库第一层 `database/` 里。
- **多图库并存**：最近图库最多保留 10 个，每个图库可再保存最多 10 个系统「照片」图库连接；连接与最近记录同时留在侧边栏与图库设置里，随时切换，不必重新打开。每个图库拥有独立的照片、相簿、图库级设置、系统图库连接、网盘挂载与智能助手对话。同一时间渲染一个“当前图库”的网格；多个连接同时保留，但不会把两个库的照片并排显示。

### 浏览
- 时间轴分组：**年 / 月 / 所有照片**，仅在图库层级显示。
  - 年：每年一张拼图卡片，点击进入该年的月总览。
  - 月：按月分段、段内按天展示拼图卡片，点击回到所有照片并定位到当天。
  - 所有照片、相簿、文件夹、智能项目：普通缩略图网格。
- 侧边栏分「拾光 / 系统图库 / 网络存储」三个分区，每个图库都是独立一套：
  - 拾光：固定（个人收藏、最近保存、地图、视频、截屏、人物、最近删除默认固定；右键任意系统项目或相簿 / 文件夹可固定或取消）、相簿（所有相簿 / 文件夹 / 智能相簿）、媒体类型、更多项目。
  - 系统图库：同一时间只连接一个库；展开后是该库自己的共享、媒体类型（视频 / 自拍 / 实况照片 / 人像 / 全景照片 / 慢动作 / 截屏 / 录屏 / 动图 / RAW）、更多项目（含最近查看、最近编辑）与相簿。
  - 网络存储：每个网盘一行，进入后浏览各自的目录。
- 侧边栏分区标题在鼠标悬停时显示「更多」菜单与收起/展开按钮，可折叠「固定」「相簿」「媒体类型」「更多项目」等分组。
- 四种照片显示形式（工具栏显示形式菜单切换，外观与尺寸跟随缩略图缩放）：正方形裁剪、完整宽高比（按原始比例分组排布、行高统一、每张下方居中显示文件名）、瀑布流（等宽多列、每列高度自适应、竖图横图混排不留空洞；卡片比其它网格大 1.5 倍，带常驻投影，悬停放大浮起）、列表（缩略图 + 文件名 + 拍摄日期 / 尺寸 / 大小，适合核对元数据）。支持滑杆、`⌘+ / ⌘- / ⌘0`、触控板捏合缩放；人物与位置的卡片墙共用同一套缩放控件（滑杆拖拽实时跟手、双指捏合、⌘+ / ⌘- / ⌘0）。
- 排序（拍摄/添加日期、标题、文件名、大小、类型、相机、地点、时长）、筛选（全部/收藏/已编辑/照片/视频/截屏/我的/未加入相簿）、关键词筛选、全文搜索（含端侧场景标签与图内文字，见「智能」）。
- 框选、方向键导航、悬停元数据浮层（可逐项开关）。
- 工具栏「信息」以浮动卡片展示：用方向键切换选中项时卡片保持打开并就地更新；拖动标题可移动，拖动右下角可调整大小，双击标题复位。
- 照片详情与查看器信息面板共用同一份分区：照片（文件名、标题、类型、尺寸、大小、时长、实况/连拍/慢动作/录屏/动图/人像/旋转）、拍摄时间（含最近查看/编辑）、相机、位置（地点分级、坐标与地图；地图用坐标图钉标注拍摄点，可拖动平移、滚轮缩放）、智能标签（端侧场景与图内文字，可就地分析单张）、关键词、所属相簿、其他（添加日期、来源、收藏/隐藏/最近删除、编辑状态）。
- 网格底部居中显示当前范围的照片与视频总数（如「1,634 张照片、67 个视频」），有选中项时自动让位给操作条。
- 视频在网格中始终显示右下角视频角标与时长（时长文案可在「排序与元数据」中关闭），与照片一眼可辨。
- **视频格式与播放**：可直接导入 30 种扩展名（MP4 / M4V / MOV / QT、AVI / MKV / WebM / FLV / F4V / WMV / ASF、MPG / MPEG / M2V / MPE / M1V / VOB / TS / M2TS / MTS / MTTS、3GP / 3G2 / OGV / RM / RMVB / DIVX / DV / MXF / AMV）。AVPlayer 原生解码 H.264 / HEVC / ProRes / MPEG-4 / VP8 / VP9 / AV1 等常见编码；系统不支持的容器可用可选的 `ffmpeg` 自动转码为 H.264 + AAC 的 MP4，并缓存到 `resources/transcodes/`，二次播放不再转码。播放器支持 0.25–4× 倍速、自动连播下一个视频（跳过照片）、循环、填充 / 适应画面、画中画、保存当前帧、全屏、音量 / 静音、上一个 / 下一个视频、可拖动控制条与完整键盘操作；视频可按类型筛选、按时长排序，导出时始终保留原文件。
- 查看器两种形态（设置 › 通用 › 浏览方式，默认「窗口内浏览」）：
  - 窗口内浏览：保留侧边栏与顶部工具条（返回、缩放滑杆、日期与序号、信息/共享/收藏/幻灯片/编辑/更多），照片带投影居中，可边看边切换相簿。
  - 全屏沉浸：查看器覆盖整个窗口并隐藏侧边栏，适合专注看图。
- 开图渐进加载：先用网格缩略图与 1024px 中等层即时占位，全尺寸解码完成后平滑淡入，看不出分辨率切换；相邻照片会预取中等层与全尺寸层，连翻不闪白。
- **大图库（数十万～数百万张）**：本地图库超过 5000 张时，「所有照片」网格的筛选、排序与计数下推到 SQLite，按每页 600 张滚动加载；查看器翻页用索引做相邻查询，连翻成本与照片总量无关。

### 组织
- 多级相簿与文件夹（新建/重命名/删除/移动/拖拽加入）。点侧边栏里的文件夹只展示它**下一层的子文件夹与相簿**（不是照片），标题旁提供「返回上一级」。
- 「所有相簿」只展示**第一层**（顶层文件夹 + 未归入文件夹的相簿），进入文件夹后再逐层展示下一层的子文件夹与相簿：每张卡片一张封面铺满（相簿取自定义封面或首张，文件夹取下一层第一个相簿的封面），名称在卡片下方，卡片大小可随工具栏缩放（⌘+ / ⌘- / ⌘0）调整。
- **自定义相簿封面**：在相簿里右键任意照片或视频可「设为相册封面」，卡片改为该张铺满展示；右键相簿卡片（或封面本身）可「恢复自动封面」回到相簿首张。封面随相簿持久化，移除该项目时自动回落。
- 把照片从网格**拖到侧边栏相簿或「所有相簿」卡片**即可加入相簿，拖动时显示缩略图与数量徽标，目标高亮。
- **相簿内拖拽排序**：在相簿网格里把照片拖到另一张照片的左/右半侧即可插入其前/后，顺序随相簿保存。
- 智能相簿：按媒体类型、收藏、已编辑、关键词、相机、镜头、地点、定位、拍摄日期、像素、文件大小、文件名、时长、场景、图内含文字自由组合条件（满足全部/任一），实时预览命中数量。
- **地图网格**（地图右上角 › 网格）：按「地点 + 连续日期」把带定位的照片切成行程段，段头显示城市、日期范围、张数与「查看地点」入口，下面是跟随缩放的照片卡片墙；换城市或隔天自动分段。「网格」是一次性浏览方式，重新进入地图页会回到默认的地图底图（卫星底图选择会被记住）。
- 个人收藏、最近保存、视频、截屏、自拍、全景、隐藏、最近删除（默认 30 天后自动清理，可在设置中调整）。
- 导入项目：按导入批次分组，每段显示「导入于 年/月/日 时:分」与该批项目数；批次 ID 随照片写入图库数据库（旧照片按添加日期归组）。
- 关键词管理；重复项目检测（按大小 + 像素尺寸分组）与逐组合并，自动按分辨率、文件大小与收藏挑出「最佳」一张。
- 人物：本地图库可用**端侧人脸聚类**在 Mac 上离线分析照片，按人脸相似度自动聚合为人物并支持重命名、查看某人的全部照片；系统图库则读取官方已有的人物/宠物识别结果。人物页顶部还会列出「常一起出现」的组合，点开可看两人同框的照片。照片移入最近删除或被隐藏后不再计入人物；永久删除时同步清理人物关系，人物没有再可见照片就自动消失（恢复照片后会重新出现）。

### 智能（端侧，不上传）
- **场景识别**：侧边栏「场景」分区点「分析照片内容…」，用 Vision 在本机为每张照片打分类标签，按人物 / 动物 / 自然风景 / 食物 / 建筑 / 交通 / 室内 / 文档 / 夜景 / 活动聚合计数，点任一行查看该场景照片；「更多」菜单里的「生成场景智能相簿」会把已识别的场景写成智能相簿（之后新分析的照片自动落入）。
- **自然语言搜索**：搜索框除文件名、标题、相机、地点外，还检索场景标签与图内文字；中文口语词（如「海边」「烟花」）会映射到 Vision 的英文标签再匹配。支持组合时间词（去年 / 今年 / 上个月 / 2024年 / 5月 / 5月20日 / 上周）、类型限定（收藏 / 视频 / 照片 / 截图 / 实况 / 已编辑）与人物名字，例如「去年 海边 狗」「2024年5月 日落」「上个月 小猫」。搜索「场景 / 图内文字 / 人物」需要先完成端侧分析或人物聚类。
- **OCR 搜图内文字**：分析时用 Vision 识别照片中的中英文文字，「更多项目 › 包含文字」列出所有含文字的照片，也可以直接在搜索框输入文字内容定位。
- **相似照片**：右键任意已分析的照片「查找相似照片」，按图像特征向量（余弦相似度）找出同场景 / 同构图的项目，网格顶部提示条可一键退出。
- **智能美化**：图库体检页右上角「智能美化」或「照片 › 智能美化…」打开推荐面板。按缩略图把照片分成**偏暗 / 偏亮 / 发灰 / 偏色 / 偏软**五组，每组显示张数、样本与说明，可「查看」选中这些照片，或「一键美化」批量生成副本（先弹窗确认）；收藏的照片会优先排在前面。分析只看缩略图，全部在本机完成，结果只在内存里、不落库。
- 分析结果（标签、OCR 文字、特征向量）只写入当前图库数据库的 `asset_analysis` 表，全程不联网；系统图库与网盘不参与分析。智能美化同样只对拾光本地图库的照片生效。

### 智能助手（云端大模型，可选）
- 入口：工具栏的 ✨ 按钮或「照片 › 智能助手…」。支持 **DeepSeek / Kimi / GLM（智谱）/ 通义千问 / 豆包（火山方舟）/ OpenAI**，统一走 OpenAI 兼容的 `chat/completions` 接口；也可以用「自定义」接入 SiliconFlow、OpenRouter、Ollama 或自建网关，接口地址与模型名都可修改。
- 默认**不上传图片**：只把当前范围摘要、照片元数据、端侧 Vision 标签与 OCR 文字发给模型；可在「设置 › 智能助手」开启「发送压缩缩略图」，此时优先发送选中照片，否则发送当前范围前几张，统一压成长边约 1024 的 JPEG（最多 6 张），原始 RAW、视频与云端照片不会发送。
- 可操作（模型通过工具调用，全部写操作先弹窗确认）：
  - **相簿**：新建相簿（可同时按主题放入项目、指定所属文件夹）、加入 / 移出项目、重命名、删除相簿（不删除照片）、移动到文件夹、设置封面。
  - **文件夹**：新建（支持多级）、重命名、删除（不删除照片）。
  - **图片与视频**：搜索与按类型筛选、收藏 / 取消收藏、隐藏 / 取消隐藏、添加 / 移除关键词、设置标题、原地压缩（有损可调质量与长边；无损保持像素，JPEG 只去元数据、其它格式转 PNG）、自动美化（生成可还原的美化副本，保留原图）、移入最近删除、从最近删除恢复、选中、在查看器中打开（视频即播放）。
  - **浏览**：切换到图库 / 收藏 / 视频 / 截屏 / 已隐藏 / 最近删除 / 指定相簿 / 指定文件夹 / 场景，并可同时设置筛选、搜索词与排序。
  - 不支持永久删除、导入、编辑原图或修改文件；系统图库连接与网盘只读，官方「照片」图库作为当前库时只写收藏 / 隐藏 / 关键词等补充元数据。
- 智能助手面板首屏提供两张主推案例（压缩这组照片、按时间地点建相簿）与四张能力卡片（检索与浏览 / 相簿与文件夹 / 图片 / 视频），点击示例即填入输入框；对话开始后保留一条轻量示例条。
- 常用案例：`把这 3 张照片压到长边 2048、质量 80`、`把这组照片做无损压缩`、`把去年在上海拍的照片整理成相簿`、`把这 8 张照片自动美化一下`、`按主题建 4 个相簿`、`把视频放进「旅行」`、`从最近删除恢复刚才那批`。
- 工具共 **26 个**：检索与浏览 5（`search_photos` / `list_albums` / `list_folders` / `list_videos` / `navigate`）、选择与打开 2（`select_photos` / `open_photo`）、相簿 7（`create_albums` / `add_photos_to_album` / `remove_photos_from_album` / `rename_album` / `delete_album` / `move_album` / `set_album_cover`）、文件夹 3（`create_folder` / `rename_folder` / `delete_folder`）、图片与视频 5（`set_favorite` / `set_hidden` / `add_keywords` / `remove_keywords` / `set_title`）、压缩 1（`compress_photos`）、美化 1（`beautify_photos`）、最近删除 2（`trash_photos` / `restore_photos`）。其中 19 个写操作必须先经用户确认；系统图库、网盘与官方「照片」库按现有权限矩阵限制。
- 每次请求最多带 40 张候选照片的元数据，避免把整个图库塞进提示词；更大范围的检索通过「应用筛选」回到现有搜索与分页管线完成。
- API Key 只保存在 macOS 钥匙串（service `com.baymax.luma.ai`），不写入图库数据库、`UserDefaults` 或日志；模型配置与对话记录随当前图库保存，切换图库会切换到各自的对话。

### 回忆
- 精选集顶部按「按月」「按地点」「收藏」「那年今日」自动生成回忆卡片，仅收录数量足够的主题。
- **那年今日置顶**：按年份（最多最近 3 年）各生成一条回忆，以大幅横幅显示在精选集最上方。
- 点击卡片进入回忆影片：均匀取样的照片按 Ken Burns 缓慢缩放平移播放，支持上一张/下一张、暂停与 Esc 退出。
- 回忆影片支持「经典 / 电影 / 清新」三种风格模板（电影风格带上下黑边），并可**导出为 mp4 视频**（1280×720、24fps、照片间交叉淡化，无声）。

### 旅行
- 按「拍摄时间 + 定位」自动识别出行：时间间隔过大或移动距离过远即切分，生成「杭州之行」这类旅行卡片，显示日期范围、天数与项目数。
- 点击旅行卡片打开故事线：首图拼贴 + 按天分组的照片，可一键「播放回忆」把整段旅行转成电影风格影片。

### 编辑与输出
- 非破坏性编辑：旋转、水平/垂直翻转、裁剪与比例、滤镜、曝光/亮度/对比度/饱和度/高光/阴影/色温/色调/锐化/暗角/降噪、自动增强；原图保留，渲染结果另存，编辑配方随图库保存以便再次调整。
- **RAW 专用解码**：DNG / CR2 / CR3 / NEF / ARW / RAF / ORF / RW2 等格式可导入，缩略图、查看器与编辑器统一走 `CIRAWFilter`（开启高光恢复）并回退到 ImageIO。
- **实况照片**：导入时自动把同名 MOV 识别为配对视频；查看器内点「实况」按钮或按 `L` 播放；导出、复制、删除都会带上配对视频。
- 复制 / 粘贴编辑点：把一张照片的参数套用到其他照片（`⌥⌘C` / `⌥⌘V`，编辑器内亦有按钮）。
- **编辑器「美化」页**：编辑器里切到「美化」，端侧分析当前画面并给出中文理由（偏暗 / 偏色 / 偏灰 / 偏软等）；可用「强度」控制力度后一键应用，也能「撤销美化」。应用只是把建议写进调整滑块，仍可继续手调，`⌘Z` 可回退。
- 导入：拖拽、文件面板、剪贴板粘贴、从系统「照片」图库选择；导入窗口支持按文件夹生成相簿与进度显示。**导入始终把原文件拷贝进图库**（不支持“引用原位置”）。批量导入按 CPU 核数并发拷贝与生成缩略图，并批量增量落盘，上千张照片也能保持流畅。
- 批量更改：一次修改所选项目的标题、拍摄日期与地点（`⌥⌘B`）。
- 导出所选 / 批量导出：可选原格式或 JPEG/HEIC/PNG/TIFF、质量、最长边尺寸、文件名规则（原始名/标题/日期+序号/序号）、导出未修改的原片；视频始终以原文件导出，实况照片会同时导出同名的配对视频。
- **专业压缩与还原**（`⌘⇧K`）：提供**有损 / 无损**两种模式。无损模式保持像素与尺寸不变：JPEG 只移除 EXIF / XMP / IPTC / 注释段，压缩数据原样保留；PNG / HEIC / TIFF 重编码为无损 PNG。有损模式可调画质 30–100%、长边（原始 / 4096 / 2560 / 2048 / 1600 / 1280 px）与输出格式（原格式 / JPEG / HEIC）。两种模式都默认仅在结果更小时替换，可选「保留原图备份」并逐字节还原；无损模式体积可能不会减小。压缩前逐张预估体积并显示进度，可随时取消。
- 打印（每张一页）；幻灯片播放（间隔、Ken Burns 效果）。
- 视频播放基于 AVPlayer，系统无法解码的编码可用 `ffmpeg`（可选，PATH 中存在时可用）转码为 H.264 后播放；一个视频播完后默认自动连播下一个视频（跳过照片），也可在设置或播放器里改为循环当前视频。播放控制条可拖动到画面任意位置（双击把手复位），支持点击时长切换剩余时间、填充 / 适应画面、上一个 / 下一个视频、倍速、音量、画中画、保存当前帧与全屏。

### 系统「照片」图库（只读 + 拾光补充元数据）
- 打开官方「照片」图库时，**它就是这个 App 的当前图库**：主侧边栏直接展示它自己的结构（共享、媒体类型、更多项目、所有项目、相簿），不再挂在「系统图库」分区下面。
- 照片内容读取 `Photos.sqlite`；拾光自己的补充元数据（收藏 / 隐藏 / 关键词 / 查看时间）写在该库的 `database/PhotosClone.sqlite`（`asset_overlays` 表），**不修改** `Photos.sqlite` 与 Apple 原图。
- 同一份库里还可以保存拾光的图库级设置（视图状态、导入选项、最近删除保留期、系统图库载入上限、元数据显示）、系统图库连接列表与网盘挂载；切换到别的图库时各自一套。
- 侧边栏「系统图库」可保存**多个**图库连接，同一时间只有一个处于连接/展开状态；点按其他图库即切换当前连接，每个连接有独立菜单（在「照片」中打开 / 重新读取 / 在访达中显示 / 断开连接）。连接新图库不会移除已有连接。
- 「系统图库」这一分区的连接列表与当前连接都跟着当前图库走：列表存在该图库自己的 `database/PhotosClone.sqlite`（`settings` 表的 `system_libraries` 键），打开 A 图库就只看到 A 自己的连接，切到 B 图库换回 B 的列表。
- 只读解析 `Photos.sqlite`，展示系统图库的照片、相簿、文件夹、人物、重复项目、导入项目等。
- 打开系统图库默认展示「所有照片」全量网格（拍摄日期从新到旧）；侧边栏的相簿与文件夹按图库原始顺序（`ZGENERICALBUM.Z_PK`）混排，与系统「照片」保持一致。
- 侧边栏相簿与文件夹默认全部收起，点箭头才展开，避免上万条相簿一次渲染卡住主线程。
- 扫描结果（索引与元数据，不含原图）缓存在当前图库的 `resources/system-cache/`：首次扫描后再次打开直接命中缓存，`Photos.sqlite` 变化时自动在后台重扫；切换图库不会共用缓存。
- 超大图库按拍摄日期从新到旧截断载入（设置 › 通用 › 系统图库载入 › 载入上限：5 万 / 10 万 / 20 万 / 不限制，默认 10 万），避免一次载入上百万项导致内存过高；该设置随当前图库保存，超出时会提示实际总数。
- 读取官方库中的自定义标题（`ZTITLE`）、实况照片与连拍标记，在元数据与信息面板中标注。
- 缩略图优先直接复用官方图库已经生成好的 `resources/derivatives`（照片取 `_1_105_c.jpeg`，视频取 `_1_102_o.jpeg` 封面帧），不再为每个格子解码 HEIC / RAW / 视频原文件；只有极少数缺失时才现场生成并缓存到当前图库的 `resources/system-thumbs/`，生成限制 3 路并发并按目标文件去重。
- 十万级以上的「所有照片」首屏只渲染 1200 张，滚动到底自动继续追加；侧边栏的相簿 / 文件夹分组与各计数按「结构版本 / 内容版本」分别缓存，扫描过程中不会反复重建上万个相簿的分桶。
- 支持把某个**相簿**或**文件夹（含子文件夹）**整体拷贝到拾光；也支持多选照片、单张右键拷贝。重复项目（同名同大小）自动跳过。

### 网络存储
- 入口：侧边栏「网络存储 › ＋」或菜单「文件 › 接入网络存储…」，均可打开同一个接入向导。
- **SMB 共享**（群晖、TrueNAS、Windows 共享等）：通过系统 NetFS 挂载后浏览与播放，只读；地址填 `smb://主机/共享名`（可在 NAS 的共享设置中查看共享名）。打开应用时会自动重连已保存的 SMB；向导通过 Bonjour 自动发现局域网设备，填入账号密码后可列出并点选共享文件夹；新添加的 SMB 默认点开即递归扫描「整个共享」，也可在浏览页切换为「按文件夹」。
- **WebDAV**（群晖 NAS 等）：可浏览、播放，并支持新建文件夹、重命名、上传、删除。
- **阿里云盘 / 百度网盘**：OAuth 2.0 桌面端授权（本地回环 `127.0.0.1:53682/callback` 接收 code），官方接口直读，只读。
- **AList / OpenList 向导**：填写地址后自动推导 WebDAV 入口，无需自建应用。
- 缩略图策略：优先服务端缩略图；WebDAV 使用 `Range` 只取文件头部 256KB 解析 EXIF 内嵌缩略图，避免整目录原图下行流量；SMB 直接从挂载目录读取文件生成本地缩略图。
- 与本地图库一致的浏览能力：网格缩放、排序、按类型或收藏筛选、关键词搜索、⌘A 全选与键盘导航、幻灯片、打印、导出所选（含批量）、设为桌面背景（先缓存到本机）；SMB 还支持「在访达中显示」与用系统应用打开。收藏只记录在拾光本机，不会写回 NAS 或网盘。
- 凭据存放于钥匙串（SMB / WebDAV 密码、OAuth 应用凭据与 token）。

```sh
swift Tools/make_icon.swift /tmp/icon_1024.png
```

## 图库结构

图库（自建库、以及直接打开的官方「照片」图库）都用同一套结构，数据放在包内第一层：

```
我的图库.photoslibrary/
├── database/PhotosClone.sqlite        # 拾光的元数据（唯一真源，官方库里与 Photos.sqlite 并列）
├── originals/<首字符>/<uuid>.<ext>
├── resources/derivatives/             # 缩略图
├── resources/renders/                 # 编辑渲染结果
├── resources/transcodes/              # 视频转码缓存
├── resources/backups/                 # 压缩前备份
├── resources/system-thumbs/           # 系统图库缩略图缓存
├── resources/system-cache/            # 系统图库扫描结果缓存
└── cloud/thumbs/                      # 网盘缩略图缓存
```

旧版本放在 `private/com.lijialong.photosclone/` 的数据会在启动/打开图库时自动上移到第一层（含官方「照片」图库，幂等，只移动一次）。

`database/PhotosClone.sqlite` 除 `assets` / `albums` / `folders` / `people` / `settings` 外，还有 `asset_analysis` 表保存端侧分析结果（场景标签、OCR 文字与归一化特征向量），以及 `asset_overlays` 表保存官方「照片」图库照片的拾光补充元数据（收藏 / 隐藏 / 关键词 / 查看时间；NULL 表示沿用 Apple 的值）。删除照片时会同步清理对应行。

**打开哪个图库就以哪个图库为准**：图库选择器、设置里的「切换到此图库」、访达双击都算打开，会切换当前图库——展示它自己的照片、相簿、系统图库连接、网盘挂载与库级设置，新导入、编辑与设置写入它自己的 `database/PhotosClone.sqlite`；不会把上一个图库的内容搬进新打开的图库。

打开官方「照片」图库时，`Photos.sqlite` 与 Apple 自带的原图只读，拾光自己的数据（`PhotosClone.sqlite`、导入副本、缩略图、编辑结果）同样写在该库第一层 `database/`、`originals/`、`resources/` 里。侧边栏「系统图库」的连接菜单只做只读浏览，不切换当前图库。

应用支持目录（`~/Library/Application Support/PhotosClone/`）：

- `ContainerPath.txt`：上次打开的图库路径
- 旧版本地库残留目录（仅在没有图库时用于迁移提示）
- 旧版的 `SystemThumbs/` 与 `SystemLibraryCache/` 不再写入；系统图库缓存已移入各图库包内。

## 已知限制

- 官方「照片」图库、SMB 共享与阿里云盘/百度网盘为只读；仅本地图库与 WebDAV 支持写入。
- SMB 依赖 macOS 系统 NetFS 挂载，共享以系统方式挂载到 `/Volumes/<共享名>`（与 Finder「连接服务器」一致），拾光复用该挂载点读取；从侧边栏断开时自动卸载。首次「整个共享」扫描大目录需要一些时间，之后刷新会重新读取。
- 暂未实现官方的高级能力：视频修剪/慢动作变速、iCloud 共享图库、屏幕保护输出。
- 回忆影片导出为无声 mp4（不含配乐）；端侧人脸聚类只在本地图库生效，需要逐张分析，首次运行较慢；系统图库只读官方已有人物结果。
- 端侧内容分析（场景标签 / OCR / 相似照片）同样只对拾光本地图库的照片生效，视频暂不参与；未分析的照片不会出现在「场景」「包含文字」或相似结果里。
- 导入始终拷贝原文件，不支持引用原位置。
- 视频转码依赖外部 `ffmpeg`，未安装时仅支持系统可解码的编码。
- **多图库**：最近图库与系统图库连接会同时保留并可快速切换，但同一时间只渲染一个“当前图库”的网格，不支持两个库并排显示。
- **压缩**：无损模式保持像素与尺寸不变（JPEG 仅移除元数据、其它格式转无损 PNG），体积可能不会减小；有损模式为高质量有损压缩，逐字节还原依赖「保留原图备份」。
- 「年 / 月」时间轴总览只在图库层级提供，相簿/文件夹使用普通网格。
- 大图库分页覆盖「所有照片」网格与媒体类型/收藏/隐藏等本地范围；「年 / 月」总览在超过 5000 张时同样走 SQL 分区（每年/每天最多取 4 张样本）。人物、回忆与地图仍基于内存索引，超百万张时首次进入这些页面会较慢。
- 图库元数据仍在启动时整体载入内存（分页只减少筛选/排序/复制的开销）；下一步是把常驻元数据也改为按需查询。
- HDR 设置对查看器内的静态图片生效（关闭时按 sRGB 显示）；系统级 EDR 行为仍由 macOS 决定。
