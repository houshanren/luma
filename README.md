# 拾光 Luma

拾光（Luma）是一个 macOS 原生照片管理应用，使用 SwiftUI + SQLite 构建，界面与交互对齐系统「照片」，并额外提供网络存储（SMB / WebDAV / 阿里云盘 / 百度网盘）与官方「照片」图库接入。

- 包标识：`com.baymax.luma`
- 最低系统：macOS 14.0
- 技术栈：Swift 5.9（SwiftPM）、SwiftUI、AppKit、Core Image、AVFoundation、SQLite（系统 `libsqlite3`）
- 第三方依赖：无

## 功能

### 图库
- 图库是一个 `.photoslibrary` 包，可放在任意文件夹或外置磁盘；应用不保存固定位置的数据。
- 首次启动没有图库时必须新建或打开一个图库（引导页），之后启动自动打开上次使用的图库。
- 按住 **Option** 启动会先弹出「选取图库」面板（列出当前图库、最近打开、`~/图片` 下的所有 `.photoslibrary`），也可从「文件 › 选取图库…」（⌥⌘O）打开。面板是独立小窗口：打开期间主窗口整窗隐藏（含窗口框架），选定前不会自动打开任何图库；选定、取消或红叉关闭后主窗口恢复（Option 启动时取消 / 红叉会回到上次使用的图库）。
- 图库选择器支持新建图库、打开任意位置图库；打开官方「照片」图库时以该图库为准，照片只读解析、拾光自己的数据写在该库第一层 `database/` 里。
- **多图库并存**：最近图库最多保留 10 个，每个图库可再保存最多 10 个系统「照片」图库连接；连接与最近记录同时留在侧边栏与图库设置里，随时切换，不必重新打开。每个图库拥有独立的照片、相簿、图库级设置、系统图库连接、网盘挂载与智能助手对话。同一时间渲染一个“当前图库”的网格；多个连接同时保留，但不会把两个库的照片并排显示。
- **单实例、单窗口**：同一时间只运行一个拾光进程，重复打开会复用已有窗口；关闭主窗口即退出应用（不会留一个空进程在 Dock 里）。
- **图库保险库**（设置 › 图库）：为 `originals`、`database` 与 `resources/renders` 生成 SHA-256 清单，备份到外置盘 / NAS 挂载点；「校验」逐文件比对大小与哈希，「恢复」只补缺失 / 损坏文件，旧文件先移入 `resources/vault-quarantine/`。系统「照片」图库请继续使用「照片」App / 时间机器，保险库只面向拾光自建图库。

### 浏览
- 时间轴分组：**年 / 月 / 所有照片**，仅在图库层级显示。
  - 年：每年一张拼图卡片，点击进入该年的月总览。
  - 月：按月分段、段内按天展示拼图卡片，点击回到所有照片并定位到当天。
  - 所有照片、相簿、文件夹、智能项目：普通缩略图网格。
- 侧边栏分「拾光 / 系统图库 / 网络存储」三个分区，每个图库都是独立一套：
  - 拾光：按「图库 / 精选集 / 固定 / 媒体类型 / 更多项目 / 场景 / 相簿」排列，媒体类型与场景默认收起。固定默认是个人收藏、人物、地图、位置、视频；右键任意系统项目或相簿 / 文件夹可固定或取消。相簿含所有相簿、文件夹与智能相簿。文件夹沿用图标，展开箭头紧贴图标、整行更靠左，层级越深缩进越大。
  - 系统图库：同一时间只连接一个库；展开后沿用同一套结构（图库 / 精选集 / 固定 / 媒体类型 / 更多项目 / 场景 / 相簿，媒体类型与场景默认收起），固定条目自动指向系统图库入口；相簿 / 文件夹 / 人物都是元数据，扫描或建索引期间会先从 `Photos.sqlite` 读出展示，不必等整库照片读完；媒体类型含视频 / 自拍 / 实况照片 / 人像 / 全景照片 / 慢动作 / 截屏 / 录屏 / 动图 / RAW，更多项目含最近查看、包含文字、值得重看、关键词等。
  - 网络存储：每个网盘一行，进入后浏览各自的目录；树结构与系统图库一致（影院（网盘自有）/ 媒体类型 / 更多项目 / 场景 / 相簿，媒体类型与场景默认收起）。「更多项目」与系统图库同名同序：个人收藏、图库体检、图库整理、值得重看、重复项目、地图、位置、人物、关键词、包含文字、最近查看、最近编辑、最近保存、最近删除、导入项目；评分 / 旗标 / 色标只记在本机（不写回网盘），最近编辑 / 最近删除 / 导入项目是同一位置的只读说明页。照片网格与顶部栏直接复用拾光 / 系统图库。
- 侧边栏分区标题在鼠标悬停时显示「更多」菜单与收起/展开按钮，可折叠「固定」「相簿」「媒体类型」「更多项目」等分组；「相簿」「媒体类型」「场景」「更多项目」的分区标题本身可点击，在右侧打开对应的二级总览（相簿 / 文件夹卡片墙、媒体类型卡片墙、场景卡片墙、更多项目入口卡片），「系统图库」「网络存储」分区标题分别打开已连接图库与已接入存储的卡片总览，无需先展开分区。「固定」默认固定个人收藏、人物、地图、位置、视频：右键任意固定项可取消固定，拖动可调整顺序；相簿、智能相簿、文件夹以及官方图库里的相簿 / 文件夹也都能固定，固定列表与顺序随当前图库保存。
- 四种照片显示形式（工具栏显示形式菜单切换，外观与尺寸跟随缩略图缩放）：正方形裁剪、完整宽高比（按原始比例分组排布、行高统一、每张下方居中显示文件名）、瀑布流（等宽多列、每列高度自适应、竖图横图混排不留空洞；卡片比其它网格大 1.5 倍，带常驻投影）、列表（缩略图 + 文件名 + 拍摄日期 / 尺寸 / 大小，适合核对元数据）。支持滑杆、`⌘+ / ⌘- / ⌘0`、触控板捏合缩放；人物与位置的卡片墙共用同一套缩放控件（滑杆拖拽实时跟手、双指捏合、⌘+ / ⌘- / ⌘0）。
- 排序（拍摄/添加日期、标题、文件名、大小、类型、相机、地点、时长）、筛选（全部/收藏/已编辑/照片/视频/截屏/我的/未加入相簿）、关键词筛选、全文搜索（含端侧场景标签与图内文字，见「智能」）。
- 框选、方向键导航、悬停元数据浮层（可逐项开关）。
- **右键菜单作用于整个选区**：选中多张后右键任意已选项目，收藏 / 取消收藏、隐藏 / 取消隐藏、添加到相簿、添加关键词、压缩、导出、在访达中显示、删除、恢复、永久删除与从云端删除都作用于全部所选；右键一张未选中的项目则只针对这一张。菜单文案按整个选区的状态显示（全部已收藏时才显示「取消收藏」）。
- **删除是完整的**：删除前会先弹出确认卡片（扇形缩略图预览 + 数量与「照片 / 视频」拆分，不可撤销的操作用红色并让「取消」作为默认按钮）。移入最近删除时项目会脱离相簿（相簿封面自动回落）；永久删除（以及保留期到点后的自动清理）会一并删除原图、实况照片配对视频、缩略图与快速缩略图、编辑渲染副本、视频转码缓存、压缩备份（`resources/backups/`）与网盘缩略图，并在数据库里清掉端侧分析、人脸扫描记录、人物关系、补充元数据与相簿引用，分片目录删空后一并移除。
- 工具栏「信息」以浮动卡片展示：用方向键切换选中项时卡片保持打开并就地更新；拖动标题可移动，拖动右下角可调整大小，双击标题复位。
- 照片详情与查看器信息面板共用同一份分区：照片（文件名、标题、类型、尺寸、大小、时长、实况/连拍/慢动作/录屏/动图/人像/旋转）、拍摄时间（含最近查看/编辑）、相机、位置（地点分级、坐标与地图；地图用坐标图钉标注拍摄点，可拖动平移、滚轮缩放）、智能标签（端侧场景与图内文字，可就地分析单张）、关键词、所属相簿、其他（添加日期、来源、收藏/隐藏/最近删除、编辑状态）。
- 网格底部居中显示当前范围的照片与视频总数（如「1,634 张照片、67 个视频」），有选中项时自动让位给操作条。
- 视频在网格中始终显示右下角视频角标与时长（时长文案可在「排序与元数据」中关闭），与照片一眼可辨。
- **视频格式与播放**：可直接导入 30 种扩展名（MP4 / M4V / MOV / QT、AVI / MKV / WebM / FLV / F4V / WMV / ASF、MPG / MPEG / M2V / MPE / M1V / VOB / TS / M2TS / MTS / MTTS、3GP / 3G2 / OGV / RM / RMVB / DIVX / DV / MXF / AMV）。AVPlayer 原生解码 H.264 / HEVC / ProRes / MPEG-4 / VP8 / VP9 / AV1 等常见编码；系统不支持的容器由内置静态 `ffmpeg`（带 libzimg）转封装为 H.264 + AAC 的 MP4，HEVC 写正确的 `hvc1` 标签，HDR 片源自动做 zscale + tonemap 色调映射，结果缓存到 `resources/transcodes/`，二次播放不再转码。网盘视频边下边播、按 Range 拖动，官方转码返回 HLS 时直接交给 AVPlayer。播放器支持外挂字幕（srt / vtt / ass / ssa，自动发现同名字幕、可手动载入、±0.5 秒偏移、字号与背景可设）、音轨切换、内嵌字幕开关、0.25–4× 倍速、自动连播下一个视频（跳过照片）、循环、填充 / 适应画面、画面旋转 90°（仅播放显示，截图跟随朝向）、画中画、保存当前帧、全屏、音量 / 静音、上一个 / 下一个视频、可拖动控制条与完整键盘操作；视频可按类型筛选、按时长排序，导出时始终保留原文件。
- 查看器两种形态（设置 › 通用 › 浏览方式，默认「窗口内浏览」）：
  - 窗口内浏览：保留侧边栏与顶部工具条（返回、缩放滑杆、信息/共享/收藏/幻灯片/编辑/更多），照片浮在由自身模糊影像铺成的灯箱底上（竖图两侧不再死黑）；画面顶部用悬浮玻璃 HUD 展示「日期 + 小进度环 + 序号」，照片参数点信息按钮查看；底部整宽胶片条可随时开关，可边看边切换相簿。
  - 全屏沉浸：查看器覆盖整个窗口并隐藏侧边栏，适合专注看图。
- 开图渐进加载：先用网格缩略图与 1024px 中等层即时占位，全尺寸解码完成后直接替换，切换照片不做淡入 / 位移；相邻照片会预取中等层与全尺寸层，连翻不闪白。
- 画面角标：角标直接贴在照片本体上（竖图 / 宽图两侧留白里不会出现角标），放大或实况播放时自动让位。RAW 照片、「人像」模式照片与实况照片在左上角依次显示「RAW / 人像 / 实况」胶囊（实况可点击原位播放）；已命名的人物会以名字胶囊排在角标下方（超过 3 人折叠为 +N）；带 GPS 的照片在右上角显示地图图钉，点按直接打开信息面板查看地点名称与地图。
- **动图**：GIF 在查看器里打开即循环播放，翻到下一张再回来会从头播放；网盘里的动图会先下载完整文件（限 80MB）再播放；已编辑的照片按静态渲染结果展示，网格仍使用首帧缩略图。
- **大图库（数十万～数百万张）**：本地图库超过 5000 张时，「所有照片」网格的筛选、排序与计数下推到 SQLite，按每页 600 张滚动加载；查看器翻页用索引做相邻查询，连翻成本与照片总量无关。

### 组织
- 多级相簿与文件夹（新建/重命名/删除/移动/拖拽加入）。点侧边栏里的文件夹只展示它**下一层的子文件夹与相簿**（不是照片），标题旁提供「返回上一级」。
- **媒体类型 / 场景总览**：点侧边栏「媒体类型」或「场景」分区标题，右侧以卡片墙展示各分类的数量与首张封面，点卡片进入该分类的照片网格；场景总览在尚未分析时提供「分析照片内容…」入口。
- **本地图像识别（SigLIP 2）**：每张照片在本机用 SigLIP 2 图文模型生成语义向量，并匹配 200+ 个中文标准标签——场景、动物、植物、食物、物品、交通、活动、照片风格、天空天气、文档票据等；同一分组只保留最可信的标签，避免「猫 / 狗 / 动物」重复堆叠。轻量 YOLO11n 额外确认猫、狗、汽车、披萨等明确主体，Vision 继续负责 OCR、人脸、人体姿态、二维码与票据 / 证件规则。模型随 App 打包，照片与识别结果都不出本机。
- **自然语言搜索**：搜索框输入「海边日落」「吃火锅」「一个女孩」这类整句时，本地文本编码器会把查询扩展成标准标签再匹配照片；「查找相似照片」也改用同一套语义向量，比旧版特征指纹更懂画面内容。
- **画面标签**：信息面板「智能标签 › 画面」按标签目录顺序列出当前照片命中的中文标签；「场景」总览新增「照片风格」「天空与天气」等分类。
- **更多项目总览**：点侧边栏「更多项目」分区标题，右侧列出个人收藏、最近删除、最近保存、最近编辑、导入项目、包含文字、值得重看、关键词、图库体检、地图、位置、人物、重复项目、已隐藏等入口卡片，点卡片直接进入对应范围；系统「照片」图库下对应手写、插图、最近查看、关键词、图库体检等只读入口。
- **关键词卡片墙**（更多项目 › 关键词，拾光 / 系统图库 / 网盘三端一致）：按关键词汇总成封面卡片墙，卡片显示 `#关键词` 与该词下的照片数量，大小跟随工具栏缩放（⌘+ / ⌘- / ⌘0）；点卡片进入该关键词的独立详情——封面页头 + 全部影像瀑布流，支持框选、双指 / 快捷键缩放、查看器与右键操作，左上角「‹ 关键词」（或标题栏返回）回到卡片墙。系统图库会同时汇总官方「照片」图库自带的标签（`Photos.sqlite` 的 `ZKEYWORD`，只读，不能从拾光删除）与拾光补充的关键词；网盘的关键词同样是拾光记录在本机的标签，不会写回远端。
- **元数据工作流**：每张照片可设 0–5 星评分、留用 / 排除旗标与红橙黄绿蓝紫灰色标；网格左下角显示评分与旗标，左侧显示色标；信息面板「整理」分区可直接点选。筛选菜单支持「评分 ≥ N / 旗标 / 色标」，并可一键清除。关键词支持 `旅行/日本/京都` 这样的 `/` 层级路径，信息面板与关键词管理按层级缩进展示；右键「评分 / 旗标 / 色标」作用于整个选区，`⌥1…⌥5` 评分、`⌥P` 留用、`⌥X` 排除、`⌥6…⌥9` 色标。系统「照片」图库的这三项写入拾光叠加数据，不改 `Photos.sqlite`。
- **打开即预热**：点开任意相簿 / 文件夹后，后台自动加载前 300 张的快速缩略图并写入本地缓存（3 路并发），首屏与回看基本秒开；快速切换相簿会取消上一次预热，避免后台任务堆积。
- 「所有相簿」只展示**第一层**（顶层文件夹 + 未归入文件夹的相簿），进入文件夹后再逐层展示下一层的子文件夹与相簿：每张卡片一张封面铺满（相簿取自定义封面或首张，文件夹取下一层第一个相簿的封面），名称在卡片下方，卡片大小可随工具栏缩放（⌘+ / ⌘- / ⌘0）调整。没有封面的相簿 / 文件夹使用程序绘制的占位插画（强调色渐变底 + 叠放照片 / 立体文件夹 + 露出的照片），不显示单调的系统文件夹图标。
- **相簿显示方式**：页头右上角与「显示 › 相簿显示方式」可在**网格 / 列表 / 拼贴墙**之间切换（系统图库的相簿层级同样支持）。列表与系统「照片」的列表视图一致：方形封面 + 右侧名称与数量，列数随窗口宽度自适应；拼贴墙把 1～4 张照片拼成无边框方块、名称叠加在底部渐变上，方块大小同样跟随工具栏缩放。选择随当前图库保存。
- **自定义相簿封面**：在相簿里右键任意照片或视频可「设为相册封面」，卡片改为该张铺满展示；右键相簿卡片（或封面本身）可「恢复自动封面」回到相簿首张。封面随相簿持久化，移除该项目时自动回落。相簿缩略图默认取相簿内的第一张（侧边栏、卡片、列表与拼贴墙一致）；系统「照片」图库则优先沿用其自身的封面设置——先取在「照片」里指定的关键照片，其次 Apple 自动挑选的关键照片，都没有时才回退到相簿第一张。
- 把照片从网格**拖到侧边栏相簿或「所有相簿」卡片**即可加入相簿，拖动时显示缩略图与数量徽标，目标高亮。
- **相簿内拖拽排序**：在相簿网格里把照片拖到另一张照片的左/右半侧即可插入其前/后，顺序随相簿保存。
- **撤销 / 重做**：删除（移入最近删除）、从最近删除恢复、收藏 / 隐藏、添加 / 移除关键词、批量更改、相簿与文件夹的新建 / 重命名 / 删除 / 移动、相簿加入 / 移出 / 排序 / 封面、合并重复项目都支持 `⌘Z` 撤销与 `⇧⌘Z` 重做。撤销栈只保留最近 30 步、且只存在于当前图库（切换图库即清空）；永久删除、清空最近删除、导入、编辑与压缩不进入撤销栈。编辑器有独立的调整历史，编辑器内的 `⌘Z` 只回退调整。
- 智能相簿：按媒体类型、收藏、已编辑、关键词、相机、镜头、地点、定位、拍摄日期、像素、文件大小、文件名、时长、场景、图内含文字自由组合条件（满足全部/任一），实时预览命中数量。
- **地图网格**（地图右上角 › 网格）：按「地点 + 连续日期」把带定位的照片切成行程段，段头显示城市、日期范围、张数与「查看地点」入口，下面是跟随缩放的照片卡片墙；换城市或隔天自动分段。「网格」是一次性浏览方式，重新进入地图页会回到默认的地图底图（卫星底图选择会被记住）。
- **视野统计**：地图左上角「N 个地点 · M 张照片」随缩放与平移实时更新为**当前视野内**的数据（缩放到街区时只算这一片），「足迹回放」与「网格」共用同一范围——网格只列视野内的照片并重新分段，足迹回放只播视野内的站点；点徽标（或右下角「显示全部位置」）回到整库口径，在地图与网格之间切换会保留这次缩放的视野。
- **照片图钉**：地图上每张带定位的照片都落在自己的真实坐标上；缩小时相邻图钉自动合成一个带数量的照片气泡，放大后重新拆回单张，滑动与缩放时聚合位置实时重排。点单张图钉打开查看器，点气泡继续放大这一簇。
- **足迹回放**（地图页 › 足迹回放）：把带定位的照片按时间顺序播成一段旅程。先把同一位置（几十米内）的连拍合并成「站」，再由统一连续时间轴同时驱动光点、镜头、站点和底部时间条；行进与旅拍停留共用一条可暂停、可拖动的时间线，途经站之间不反复启停。默认「丝滑」按真实距离与镜头高度的比例统一画面中的前进感，而非按现实车速播放；常规街区和跨城段保持一致的视觉节奏，极短移动也保留最短可辨认时长。镜头高度随本段距离缩放，街区级的近距离移动也会被拉到满屏可见的尺度，跨城航段自动升到高空；航向沿最短圆弧平滑衔接并看向路线前方，光点沿大圆逐帧推进、轨迹随之生长，抵达站点时翻开该站的实拍照片。卫星三维底图、胶片颗粒、暗角与相机日期水印提供拟物质感；底部胶片式时间条按照片密度绘制，支持慢 / 丝滑 / 快三档（默认丝滑）、播放中无缝变速、空格暂停、按时间拖动、重播、自由查看后连续重新跟随与 Esc 关闭。播放结束后镜头自动拉远到全览，整条足迹加粗并描一道白色芯线，起点 / 终点各挂一枚日期徽章；小结收在贴底的「旅程完成」档案条里（日期范围、总里程 / 站点 / 地点 / 天，以及「再看一遍」「完成」），把中间整幅路线完整让出来。
- **位置详情**：点开任意地点进入独立详情，页头带封面与坐标网格、显示聚类中心坐标，并随滚动收缩成紧凑栏；「摘要 / 全部」双视图——摘要提供到访轨迹曲线、四季流转、一天中的时段、镜头里的地标、同行的人、色彩气质与每年高光；全部按月年排成「旅行日志」，年份旁带四季比例条，照片用瀑布流拼贴并支持拖拽框选。所有统计都由当前地点的照片元数据在本机派生。地名优先读取官方图库自带的逆地理数据；缺失时用系统逆地理编码补齐，境外坐标在系统编码无结果时回退到内置城市库（GeoNames cities15000，随 App 打包）按最近城市补到国家 / 城市级。
- 个人收藏、最近保存、视频、截屏、自拍、全景、隐藏、最近删除（默认 30 天后自动清理，可在设置中调整）。个人收藏页顶栏提供「全部 / 年 / 类型 / 地点 / 相机 / 人物」浏览切换（默认先看年份，选择随当前图库保存）：全部保持平铺网格；其余每个维度单独一屏，用大卡片汇总——**年份**（最新年份通栏大卡 + 年份拼图卡）、**类型**（缩略图拼图 + 占比进度条，照片类型通栏主卡）、**地点**（城市明信片）、**相机**（按品牌聚合，相机 / 手机设备插画 + 品牌配色，并列出常见机型）、**人物**（已命名人物头像）。点任意卡片只显示该分类的收藏，顶栏「← 维度」返回；系统图库收藏超过 30,000 项时只统计最近一批。
- 导入项目：按导入批次分组，每段显示「导入于 年/月/日 时:分」与该批项目数；批次 ID 随照片写入图库数据库（旧照片按添加日期归组）。系统图库的「导入项目」按导入日期分组，展示与拾光一致。
- 关键词管理；**重复项目 / 相似照片**：精确重复优先按 SHA-256 归组（没有哈希的旧资产继续按文件大小 + 像素尺寸兜底），标注「建议保留」及理由（收藏、含编辑、已入相簿、有标题或关键词、分辨率 / 文件大小），支持单组「合并 N 个项目」与「合并全部」。相似照片按 64 位 dHash + 拍摄时间窗口 + 宽高比归组，只展示、不自动合并；可逐组「保留推荐，其余移入最近删除」并二次确认。合并会保留一个版本、汇总收藏 / 评分 / 旗标 / 色标 / 关键词 / 标题 / 地点 / 相簿关系，其余副本移入「最近删除」（30 天内可恢复）。系统「照片」图库同样提供重复项目视图，但因其只读，动作改为「隐藏其余副本」「拷贝保留版本到拾光」与「在照片中合并」，不会删除 Apple 的照片。网络存储也提供只读的重复项目页，提示到网盘 App 中合并。
- 人物：本地图库可用**端侧人脸聚类**在 Mac 上离线分析照片，按人脸相似度自动聚合为人物并支持重命名、查看某人的全部照片；系统图库则读取官方已有的人物/宠物识别结果（包含官方尚未命名的聚类，与系统「照片」的人物列表一致）。人物页顶部还会列出「常一起出现」的组合，点开可看两人同框的照片。**总览顶栏提供「全部 / 已命名 / 待命名 / 宠物」聚合切换**（与「位置」的省 / 市 / 区县 / 街道同一套控件）：全部视图平铺展示所有人物与宠物、不按命名状态分节；只有点选某一项后才收窄到该分类，选择随当前图库保存。照片移入最近删除或被隐藏后不再计入人物；永久删除时同步清理人物关系，人物没有再可见照片就自动消失（恢复照片后会重新出现）。点开某个人物后提供**摘要 / 全部**两种视图：页头是清晰的大图封面，滚动时自动收缩成紧凑栏；摘要以大图封面 + 一句话人物画像开场，配合年度轨迹、光线偏好、常去之地、常一起出现与「色彩气质」（缩略图平均色）等派生卡片，并横向列出每年最值得回看的高光照片；全部则用年份渐变大字做时间节点，按年分段以瀑布流拼贴展示这个人的所有照片。所有统计都由照片元数据在本机派生，不上传、不落库。

### 智能（端侧，不上传）
- **场景识别**：侧边栏「场景」分区点「分析照片内容…」，用 Vision 在本机为每张照片打分类标签，按人物 / 动物 / 宠物 / 畜牧农场 / 鸟类 / 鱼与海洋生物 / 植物花卉 / 自然风景 / 食物 / 建筑 / 交通 / 室内 / 文档 / 票据 / 证件 / 证件照 / 二维码条码 / 名胜古迹 / 夜景 / 活动聚合计数，点任一行查看该场景照片；「更多」菜单里的「生成场景智能相簿」会把已识别的场景写成智能相簿（之后新分析的照片自动落入）。动物细分（猫、狗、牛、羊、马、猪、鸟、鱼、兔）与植物花卉直接来自 Vision 分类标签；**票据（发票 / 收据 / 门票 / 登机牌）、证件（身份证 / 护照 / 驾驶证等）与名胜古迹靠 OCR 关键词判定**，二维码 / 条码用 `VNDetectBarcodesRequest` 检测并把载荷并入可搜索文字，**证件照是单人脸 + 竖幅/方幅 + 居中的人脸启发式**（纯色背景半身人像可能误判）。翻拍类照片会先用 `VNDetectDocumentSegmentationRequest` 裁出文档区域再 OCR，小字命中率更高；发票与身份证再经 `LumaCore/DocumentText` 规则校验（发票强特征词组合、18 位身份证的出生日期 + GB 11643 校验位），比纯关键词更少误判。**「名胜古迹」会结合位置**：优先用照片 EXIF 坐标就近匹配内置地标表（国内主要名胜 + 部分海外地标，半径按景区范围放宽），没有坐标时再用 POI / 城市 / 区县文字匹配；信息面板「智能标签」会显示具体地标名（如「地标 西湖」）。调整识别项后可用「重新分析全部照片…」覆盖更新历史结果。「场景」分区的「更多」菜单提供三个入口：「分析新照片…」只补未分析的照片、「重新分析全部照片…」从头覆盖重跑、「重置（清空结果）…」二次确认后删除全部分析结果（场景标签、图内文字与相似检索特征，照片本身不受影响）。
- **自然语言搜索**：搜索框除文件名、标题、相机、地点外，还检索场景标签与图内文字；中文口语词（如「海边」「烟花」）会映射到 Vision 的英文标签再匹配。支持组合时间词（去年 / 今年 / 上个月 / 2024年 / 5月 / 5月20日 / 上周）、类型限定（收藏 / 视频 / 照片 / 截图 / 实况 / 已编辑）与人物名字，例如「去年 海边 狗」「2024年5月 日落」「上个月 小猫」。搜索「场景 / 图内文字 / 人物」需要先完成端侧分析或人物聚类。
- **OCR 搜图内文字**：分析时用 Vision 识别照片中的中英文文字，「更多项目 › 包含文字」列出所有含文字的照片，也可以直接在搜索框输入文字内容定位。
- **人物识别**：拾光（本地图库）用本机 Vision 检测人脸并聚类为人物，结果只保存在当前图库。人物页顶部常驻识别入口：「继续识别（剩余 N 张）」只分析新增 / 尚未处理过的照片，已有聚类与命名全部保留；「重新识别…」会二次确认后清空扫描记录与聚类（含命名）再从头分析。系统「照片」图库的人物来自官方端侧识别，人物页提供「刷新识别结果」重新读取。人物卡片形状（圆形 / 圆角方形）在设置 › 浏览 › 人物总览切换，圆角方形与系统「照片」的人物平铺一致，随当前图库保存。
- **相似照片**：右键任意照片「查找相似照片」，按图像特征向量（余弦相似度）找出同场景 / 同构图的项目，网格顶部提示条可一键退出；本地图库用落库特征，系统「照片」图库与网络存储对当前范围最多 80 张缩略图现算特征（写入 `system_analysis` / `cloud_assets`，下次直接复用），顶部胶囊可退出相似范围。
- **智能美化**：图库体检页右上角「智能美化」或「照片 › 智能美化…」打开推荐面板。按缩略图把照片分成**偏暗 / 偏亮 / 发灰 / 偏色 / 偏软**五组，每组显示张数、样本与说明，可「查看」选中这些照片，或「一键美化」批量生成副本（先弹窗确认）；收藏的照片会优先排在前面。分析只看缩略图，全部在本机完成，推荐结果按范围写入当前图库的 `derived_reports`，重开面板直接回填。网络存储只读：美化会读取云端大图后按同一套参数渲染，并把结果作为**新照片保存到拾光本地图库**，网盘原图不变。系统「照片」图库有两种出口：默认从官方原图渲染后另存到拾光；当它作为当前图库时，还可以选择「美化原图」，经系统照片接口（PhotoKit）写回，并在「照片」里保留可撤销的调整记录。
- 分析结果（标签、OCR 文字、二维码 / 条码载荷、特征向量）只写入当前图库数据库的 `asset_analysis` 表，全程不联网。系统图库也支持同一套端侧识别（侧边栏「场景 › 识别照片内容…」，在后台持续识别、结果逐张出现、可随时停止；「更多」菜单提供「继续识别…」断点续跑、「重新识别全部照片…」清空后从头识别与「重置（清空结果）…」删除本机识别缓存三个入口，后两者需二次确认），结果写当前图库的 `system_analysis`（按图库路径），**不写 `Photos.sqlite`**；图库被替换时按签名整批失效。打开图库不会自动识别，需手动点「识别照片内容…」；在本次运行中主动开启且未点停止时，重新载入后才会对新增照片续跑。系统「照片」图库的体检与美化推荐同样写入 `derived_reports`，重开页面直接回填。网络存储的识别 / EXIF / 人体聚类 / 体检 / 美化推荐都落在 `cloud_assets`、`cloud_people` 与 `derived_reports`，断开挂载时一起清理，不上传任何照片。系统「照片」图库的清理能力：「更多项目 › 图库体检」用当前已载入照片的缩略图检查模糊与相似连拍；扫描一开始就展示可立刻确定的过大视频，并随进度实时刷新模糊照片与已检查数量，相似连拍在清晰度扫完后补齐；暂停体检会保留已检查的部分结果并补齐相似连拍，可以继续查看与处理。当官方库作为当前图库时，相似备选可以经 PhotoKit 移入「照片」的最近删除（30 天内可恢复），其余情况只预览。

### 智能助手（云端大模型，可选）
- 入口：工具栏的 ✨ 按钮或「照片 › 智能助手…」。支持 **DeepSeek / Kimi / GLM（智谱）/ 通义千问 / 豆包（火山方舟）/ OpenAI**，统一走 OpenAI 兼容的 `chat/completions` 接口；也可以用「自定义」接入 SiliconFlow、OpenRouter、Ollama 或自建网关，接口地址与模型名都可修改。
- 默认**不上传图片**：只把当前范围摘要、照片元数据、端侧 Vision 标签与 OCR 文字发给模型；可在「设置 › 助手」开启「发送压缩缩略图」，此时优先发送选中照片，否则发送当前范围前几张，统一压成长边约 1024 的 JPEG（最多 6 张），原始 RAW、视频与云端照片不会发送。
- 可操作（模型通过工具调用，全部写操作先弹窗确认）：
  - **相簿**：新建相簿（可同时按主题放入项目、指定所属文件夹）、加入 / 移出项目、重命名、删除相簿（不删除照片）、移动到文件夹、设置封面。
  - **文件夹**：新建（支持多级）、重命名、删除（不删除照片）。
  - **图片与视频**：搜索与按类型筛选、收藏 / 取消收藏、隐藏 / 取消隐藏、添加 / 移除关键词、设置标题、原地压缩（有损可调质量与长边；无损保持像素，JPEG 只去元数据、其它格式转 PNG）、自动美化（生成可还原的美化副本，保留原图）、移入最近删除、从最近删除恢复、选中、在查看器中打开（视频即播放）。
  - **浏览**：切换到图库 / 收藏 / 视频 / 截屏 / 已隐藏 / 最近删除 / 指定相簿 / 指定文件夹 / 场景，并可同时设置筛选、搜索词与排序。
  - 不支持永久删除、导入、编辑原图或修改文件；系统图库连接与网盘只读，官方「照片」图库作为当前库时只写收藏 / 隐藏 / 关键词等补充元数据。
- 智能助手面板首屏提供两张主推案例（压缩这组照片、按时间地点建相簿）与五张能力卡片（检索与浏览 / 相簿与文件夹 / 图片 / 视频 / 网络资源），点击示例即填入输入框；对话开始后保留一条轻量示例条。
- 常用案例：`把这 3 张照片压到长边 2048、质量 80`、`把这组照片做无损压缩`、`把去年在上海拍的照片整理成相簿`、`把这 8 张照片自动美化一下`、`按主题建 4 个相簿`、`把视频放进「旅行」`、`从最近删除恢复刚才那批`、`搜一下 XX 并播放第一条`、`把今天新片加入稍后看`。
- 工具共 **42 个**：照片检索与浏览 4（`search_photos` / `list_albums` / `list_folders` / `list_videos`）、导航与选择 3（`navigate` / `select_photos` / `open_photo`）、相簿与文件夹 10（`create_albums` / `add_photos_to_album` / `remove_photos_from_album` / `rename_album` / `delete_album` / `move_album` / `set_album_cover` / `create_folder` / `rename_folder` / `delete_folder`）、图片与视频 7（`set_favorite` / `set_hidden` / `add_keywords` / `remove_keywords` / `set_title` / `compress_photos` / `beautify_photos`）、最近删除 2（`trash_photos` / `restore_photos`）、影院 7（`list_cinema_items` / `list_cinema_scopes` / `cinema_tree` / `search_cinema_candidates` / `apply_cinema_match` / `scrape_cinema` / `match_cinema`）、网络资源 9（`list_catalog_sources` / `search_catalog` / `catalog_new_today` / `list_catalog_following` / `list_catalog_watchlist` / `browse_catalog` / `play_catalog_item` / `set_catalog_watchlist` / `follow_catalog_person`）。其中 24 个写操作必须先经用户确认；系统图库、网盘与官方「照片」库按现有权限矩阵限制。
- 每次请求最多带 40 张候选照片的元数据，避免把整个图库塞进提示词；更大范围的检索通过「应用筛选」回到现有搜索与分页管线完成。
- API Key 只保存在 macOS 钥匙串（service `com.baymax.luma.ai`），不写入图库数据库、`UserDefaults` 或日志；模型配置与对话记录随当前图库保存，切换图库会切换到各自的对话。

### 回忆
- 精选集顶部按「按月」「按地点」「收藏」「那年今日」自动生成回忆卡片，仅收录数量足够的主题。
- **那年今日置顶**：按年份（最多最近 3 年）各生成一条回忆，以大幅横幅显示在精选集最上方。
- 点击卡片进入回忆影片：均匀取样的照片按 Ken Burns 缓慢缩放平移播放，支持上一张/下一张、暂停与 Esc 退出。
- 回忆影片支持「经典 / 电影 / 清新」三种风格模板（电影风格带上下黑边），并可**导出为 mp4 视频**（1280×720、24fps、照片间交叉淡化，无声）。

### 旅行
- 按「拍摄时间 + 定位」自动识别出行：时间间隔过大或移动距离过远即切分，生成「杭州之行」这类旅行卡片，显示日期范围、天数与项目数。

### 值得重看
- 只收录拍摄超过两年、且一年以上没有在拾光里打开过的照片；越久没翻开、拍摄越早越靠前，收藏的照片略微加权。
- 顶部先给一张**今日重看**大图：每天轮换一张最久未翻开的照片，标注「N 年前」、月份与地点、上次打开是多久前，可「翻开这张」或「换一张」，也可直接跳到这一年的全部旧照片。
- 旧照片按**人物 / 地点 / 场景 / 年份**拆成主体：切换胶囊只看一类主体，每张主体卡片显示张数与时间跨度，人物主体带人脸头像；「只看未打开」可过滤掉已经看过的照片。
- 进入主体后是一页有叙事感的详情：封面横幅写明最早一张的月份与地点，页头汇总张数、年份跨度、地点数与从未打开的张数；**年份胶囊**可一键只看某一年，照片墙支持「最早优先 / 最近优先」与框选。
- 底部的「时光碎片」瀑布流直接翻看最久未打开的照片；所有分组都在本机由照片元数据派生，不落库、不上传。

### 编辑与输出
- 非破坏性编辑：旋转、水平/垂直翻转、裁剪与比例、滤镜、曝光/亮度/对比度/饱和度/高光/阴影/色温/色调/锐化/暗角/降噪、自动增强；原图保留，渲染结果另存，编辑配方随图库保存以便再次调整。
- **RAW 专用解码**：DNG / CR2 / CR3 / NEF / ARW / RAF / ORF / RW2 等格式可导入，缩略图、查看器与编辑器统一走 `CIRAWFilter`（开启高光恢复）并回退到 ImageIO。
- **实况照片**：导入时自动把同名 MOV 识别为配对视频；查看器内点「实况」按钮或按 `L` 播放；导出、复制、删除都会带上配对视频。
- 复制 / 粘贴编辑点：把一张照片的参数套用到其他照片（`⌥⌘C` / `⌥⌘V`，编辑器内亦有按钮）。
- **编辑器「美化」页**：编辑器里切到「美化」，端侧分析当前画面并给出中文理由（偏暗 / 偏色 / 偏灰 / 偏软等）；可用「强度」控制力度后一键应用，也能「撤销美化」。应用只是把建议写进调整滑块，仍可继续手调，`⌘Z` 可回退。
- 导入：拖拽、文件面板、剪贴板粘贴、从系统「照片」图库选择；导入窗口支持按文件夹生成相簿与进度显示。**导入始终把原文件拷贝进图库**（不支持“引用原位置”）。批量导入按 CPU 核数并发拷贝与生成缩略图，并批量增量落盘，上千张照片也能保持流畅。**导入增强检测**：导入前计算 SHA-256 并与图库 / 本批次已有文件比对，默认跳过字节完全相同的文件；导入前检查目标磁盘可用空间；复制完成后可重新计算目标文件哈希，确认写入完整。进度条会显示已导入、跳过重复、失败与已校验数量。
- 批量更改：一次修改所选项目的标题、拍摄日期与地点（`⌥⌘B`）。
- 导出所选 / 批量导出：可选原格式或 JPEG/HEIC/PNG/TIFF、质量、最长边尺寸、文件名规则（原始名/标题/日期+序号/序号）、导出未修改的原片；视频始终以原文件导出，实况照片会同时导出同名的配对视频。
- **专业压缩与还原**（`⌘⇧K`）：提供**有损 / 无损**两种模式。无损模式保持像素与尺寸不变：JPEG 只移除 EXIF / XMP / IPTC / 注释段，压缩数据原样保留；PNG / HEIC / TIFF 重编码为无损 PNG。有损模式可调画质 30–100%、长边（原始 / 4096 / 2560 / 2048 / 1600 / 1280 px）与输出格式（原格式 / JPEG / HEIC）。两种模式都默认仅在结果更小时替换，可选「保留原图备份」并逐字节还原；无损模式体积可能不会减小。压缩前逐张预估体积并显示进度，可随时取消。
- 打印（每张一页）；幻灯片播放（间隔、Ken Burns 效果）。
- 视频播放基于 AVPlayer，系统无法解码的编码可用 `ffmpeg`（可选，PATH 中存在时可用）转码为 H.264 后播放；一个视频播完后默认自动连播下一个视频（跳过照片），也可在设置或播放器里改为循环当前视频。播放控制条可拖动到画面任意位置（双击把手复位），支持点击时长切换剩余时间、填充 / 适应画面、上一个 / 下一个视频、倍速、音量、画中画、保存当前帧与全屏。

### 系统「照片」图库（读取官方库 + 拾光补充元数据 + PhotoKit 写回）
- 打开官方「照片」图库时，**它就是这个 App 的当前图库**：主侧边栏直接展示它自己的结构（图库 / 精选集 / 媒体类型 / 更多项目 / 相簿），不再挂在「系统图库」分区下面。
- 照片内容读取 `Photos.sqlite`；拾光自己的补充元数据（收藏 / 隐藏 / 关键词 / 查看时间）写在该库的 `database/PhotosClone.sqlite`（`asset_overlays` 表），**不修改** `Photos.sqlite` 与 Apple 原图。需要真实写入时只走系统照片接口（PhotoKit），由「照片」自己更新原图与数据库：编辑 / 删除照片、新建 / 重命名 / 删除相簿、把照片加入或移出相簿、相簿内移到最前 / 最后、收藏与隐藏都可以写回（需在系统设置里授予照片读写权限）。关键词与照片标题 PhotoKit 不开放，仍只记录在拾光。文件夹管理尚未接入：可在「设置 › 浏览 › 系统图库写入」点「验证能否写入文件夹…」，拾光会临时建一个文件夹再删除并告知结果。
- 同一份库里还可以保存拾光的图库级设置（视图状态、导入选项、最近删除保留期、系统图库载入上限、元数据显示）、系统图库连接列表与网盘挂载；切换到别的图库时各自一套。
- 侧边栏「系统图库」可保存**多个**图库连接，同一时间只有一个处于连接/展开状态；点按其他图库即切换当前连接，每个连接有独立菜单（在「照片」中打开 / 重新读取 / 在访达中显示 / 断开连接）。连接新图库不会移除已有连接；断开前会弹出确认卡片（来源图标 + 图库名称 + 影响说明），只移除侧边栏连接，不会删除该图库的任何照片或元数据。
- 「系统图库」这一分区的连接列表与当前连接都跟着当前图库走：列表存在该图库自己的 `database/PhotosClone.sqlite`（`settings` 表的 `system_libraries` 键），打开 A 图库就只看到 A 自己的连接，切到 B 图库换回 B 的列表。
- 只读解析 `Photos.sqlite`，展示系统图库的照片、相簿、文件夹、人物、重复项目、导入项目等。
- 系统图库的「重复项目」使用同一套分组卡片视图（按文件大小 / 像素尺寸，并补充官方标记为重复的项目）；官方库只读，因此提供「隐藏其余副本」（写拾光补充元数据，可在「已隐藏」恢复）、「拷贝保留版本到拾光」与「在「照片」中合并」，不会删除或改写 Apple 的照片。
- 打开系统图库默认展示「所有照片」全量网格（拍摄日期从新到旧）；侧边栏的相簿与文件夹按图库原始顺序（`ZGENERICALBUM.Z_PK`）混排，与系统「照片」保持一致。
- 扫描是**边读边显示**的：主库按拍摄日期从新到旧分批到达（设置载入上限与「不限制」都一样），视频、截屏等媒体类型不必等整库扫完才出现；顶部的进度胶囊显示已读取数量，列表会持续增量刷新。十万项以上的大图库在建立浏览索引期间同样逐批出图（先保留开头一段供浏览，索引就绪后自动切换成 SQL 窗口），不会一直停在「正在读取系统图库…」。
- 进入官方相簿时沿用它在 `Photos.sqlite` 关联表里保存的顺序（拍摄日期 / 添加日期 / 手动拖拽都与系统「照片」一致）；在排序菜单里改选其它字段时按拾光的排序显示。
- 点侧边栏里的文件夹只展示它**下一层的子文件夹与相簿**（卡片形式，与系统「照片」一致），不会把整个子树的照片直接铺开；卡片可继续点进去，卡片大小随工具栏缩放。
- 点侧边栏「相簿」「媒体类型」「更多项目」分区标题同样在右侧打开对应的卡片总览：根层相簿 / 文件夹卡片墙、各媒体类型数量与封面、各工具入口；点「系统图库」分区标题可集中查看已连接的图库卡片并切换。
- 侧边栏相簿与文件夹默认全部收起，点箭头才展开，避免上万条相簿一次渲染卡住主线程。
- 扫描结果（索引与元数据，不含原图）缓存在当前图库的 `resources/system-cache/`：首次扫描后再次打开直接命中缓存，`Photos.sqlite` 变化时自动在后台重扫；切换图库不会共用缓存。
- 超大图库按拍摄日期从新到旧截断载入（设置 › 通用 › 系统图库载入 › 载入上限：不限制 / 5 万 / 10 万 / 20 万 / 50 万 / 100 万 / 150 万项，默认不限制）；怕内存吃紧时可自行设上限，该设置随当前图库保存，超出时会提示实际总数。
- 读取官方库中的自定义标题（`ZTITLE`）、实况照片与连拍标记，在元数据与信息面板中标注。
- **连拍快照**：「连拍快照」分类按组展示代表照片（多成员组取官方的键照片，单成员组自身即代表），与官方「照片」一致；打开代表照片即进入整组浏览——顶栏显示「连拍快照（N张照片）」与组内序号，底部胶片条可切换组内每一张，`P` 按拍摄顺序连播整组；「进行选择…」进入组内多选，可收藏所选，或保留所选并把其余移入「照片」的最近删除（30 天内可恢复）。
- 缩略图优先直接复用官方图库已经生成好的 `resources/derivatives`（照片取 `_1_105_c.jpeg`，视频取 `_1_102_o.jpeg` 封面帧），不再为每个格子解码 HEIC / RAW / 视频原文件；只有极少数缺失时才现场生成并缓存到当前图库的 `resources/system-thumbs/`，生成限制 3 路并发并按目标文件去重。
- 十万级以上的「所有照片」首屏只渲染 1200 张，滚动到底自动继续追加；侧边栏的相簿 / 文件夹分组与各计数按「结构版本 / 内容版本」分别缓存，扫描过程中不会反复重建上万个相簿的分桶。
- 支持把某个**相簿**或**文件夹（含子文件夹）**整体拷贝到拾光；也支持多选照片、单张右键拷贝。重复项目（同名同大小）自动跳过。

### 网络存储
- 入口：侧边栏「网络存储 › ＋」或菜单「文件 › 接入网络存储…」，均可打开同一个接入向导。
- 点侧边栏「网络存储」分区标题可在右侧集中查看所有已接入存储的卡片（名称、类型与地址、当前打开状态），点卡片直接进入该存储；卡片右键可刷新、编辑连接或断开。断开前同样先确认：会移除挂载并清理本机缓存的缩略图与收藏记录，网盘上的文件不受影响。
- **SMB 共享**（群晖、TrueNAS、Windows 共享等）：通过系统 NetFS 挂载后浏览与播放，只读；地址填 `smb://主机/共享名`（可在 NAS 的共享设置中查看共享名）。打开应用时会自动重连已保存的 SMB；向导通过 Bonjour 自动发现局域网设备，填入账号密码后可列出共享文件夹——单击选中整个共享，双击进入共享后逐层浏览子目录（面包屑与「上一级 / 共享列表」返回），单击子目录即把地址定位到该目录，双击继续下钻，地址形如 `smb://主机/共享名/子目录`；再次接入同一台 NAS 时会自动复用已保存的账号与钥匙串密码并直接列出共享（界面提示「已复用…」），不用重输；新添加的 SMB 默认点开即递归扫描选中的目录，也可在浏览页切换为「按文件夹」。
- **WebDAV**（群晖 NAS 等）：可浏览、播放，并支持新建文件夹、重命名、上传、删除。
- **阿里云盘 / 百度网盘**：OAuth 2.0 桌面端授权（本地回环 `127.0.0.1:53682/callback` 接收 code），官方接口直读，只读。
- **AList / OpenList 向导**：填写地址后自动推导 WebDAV 入口，无需自建应用。
- 缩略图策略：优先服务端缩略图；WebDAV 使用 `Range` 只取文件头部 256KB 解析 EXIF 内嵌缩略图，避免整目录原图下行流量；SMB 直接从挂载目录读取文件生成本地缩略图。
- **网盘 EXIF**：进入目录后自动从文件头部读取前 200 张的拍摄时间、相机 / 镜头、光圈 / 快门 / ISO 与 GPS（WebDAV 与官方网盘用 `Range`，SMB 直接读挂载文件；不下载整张原图），侧边栏「媒体类型」下显示读取进度与「继续读取（剩余 N 张）」。读取结果写回当前列表并落当前图库的 `cloud_assets`（按挂载 + 路径，远端文件大小变化即失效），信息面板的拍摄时间 / 相机 / 位置分区随之生效，并驱动「更多项目」里的地图、位置、人物与值得重看；重开网盘会直接回填，不必重新请求。
- 与本地图库一致的浏览能力：网格缩放、排序、按类型或收藏筛选、关键词搜索、⌘A 全选与键盘导航、幻灯片、打印、导出所选（含批量）、设为桌面背景（先缓存到本机）；SMB 还支持「在访达中显示」与用系统应用打开。收藏只记录在拾光本机，不会写回 NAS 或网盘。
- **打开网盘后的分类浏览**：与本地图库一样分「媒体类型 / 场景 / 更多项目」——全部项目、视频、照片、截屏（按文件名识别）、动图、RAW、个人收藏、包含文字、值得重看、地图、位置、人物、重复项目、图库体检；每个网盘行左侧有独立的展开箭头（点箭头可单独收起 / 展开该网盘的分类，点名称则切换到这个网盘），三组分类也各自带收起箭头。点「媒体类型」「更多项目」分区标题会像拾光一样打开卡片总览（数量 + 封面，点卡片回到对应范围或只读派生页），左上角返回或再次点标题退出总览。点左侧「场景 › 识别内容」后，拾光在本机用 Vision 识别当前网盘列表（每次最多 120 张，可随时停止），完成后即可按自然风景 / 食物 / 室内等场景浏览，并按图内文字筛选；识别结果写入当前图库的 `cloud_assets` 缓存（不上传、不写网盘），重开目录直接回填。地图 / 位置复用拾光的地图与地点卡片墙（GPS 来自网盘 EXIF，缺地名时本机逆地理编码）；人物在本机对网盘缩略图做人脸聚类，结果写入 `cloud_people`；重复项目按「文件大小 + 像素尺寸」分组，只读展示并提示到网盘 App 合并；值得重看用 EXIF 拍摄时间与本机查看记录判定（`cloud_assets.viewed_at`）；图库体检用当前目录缩略图检查清晰度与相似连拍，结果按目录落 `derived_reports`（只预览，不提供清理动作）；右键照片可「查找相似照片」（现算端侧特征并缓存）；智能美化会读取云端大图渲染后把副本保存到拾光本地图库。
- 凭据存放于钥匙串（SMB / WebDAV 密码、OAuth 应用凭据与 token）。

## 构建与运行

```sh
# 构建（默认 release），产物为 Luma.app
./build.sh

# 构建 debug 版本
./build.sh debug

# 运行
open Luma.app
```

`build.sh` 会执行 `swift build`，把可执行文件、`Resources/Info.plist`、`Resources/AppIcon.icns`、`Resources/PrivacyInfo.xcprivacy` 组装成 `Luma.app`；默认 ad-hoc 签名。设置 `CODESIGN_IDENTITY` 时会使用 hardened runtime + `Resources/Luma.entitlements` 签名；`PACKAGE=1` 会额外生成 `Luma-<版本>-macOS.zip`；`NOTARIZE=1` 配合 `APPLE_ID` / `TEAM_ID` / `APP_PASSWORD` 会调用 `notarytool` 公证并装订：

```sh
# 开发者证书签名 + 打包
CODESIGN_IDENTITY="Developer ID Application: ..." PACKAGE=1 ./build.sh

# 公证（需要 app-specific password）
CODESIGN_IDENTITY="Developer ID Application: ..." \
APPLE_ID="you@example.com" TEAM_ID="TEAMID" APP_PASSWORD="xxxx-xxxx-xxxx-xxxx" \
NOTARIZE=1 ./build.sh
```

纯逻辑检查（布局算法、缩略图档位；命令行工具链无 XCTest，用断言可执行目标代替）：

```sh
swift run LumaCoreChecks
```

也可以直接用 Xcode 打开 `Package.swift` 运行（可执行目标 `PhotosClone`，运行产物名与应用名不同，界面标题为「拾光」）。

图标由 `Tools/make_icon.swift` 绘制（输出 1024 PNG，可用 `iconutil` 打包为 `Resources/AppIcon.icns`）：

```sh
swift Tools/make_icon.swift /tmp/icon_1024.png
```

## 图库结构

图库（自建库、以及直接打开的官方「照片」图库）都用同一套结构，数据放在包内第一层：

```
我的图库.photoslibrary/
├── database/PhotosClone.sqlite        # 拾光的元数据（唯一真源，官方库里与 Photos.sqlite 并列）
├── originals/<首字符>/<uuid>.<ext>
├── resources/derivatives/             # 缩略图
├── resources/renders/                 # 编辑渲染结果
├── resources/transcodes/              # 视频转码缓存
├── resources/backups/                 # 压缩前备份
├── resources/vault-quarantine/        # 保险库恢复前的损坏文件隔离区
├── resources/system-thumbs/           # 系统图库缩略图缓存
├── resources/system-cache/            # 系统图库扫描结果缓存
└── cloud/thumbs/                      # 网盘缩略图缓存
```

旧版本放在 `private/com.lijialong.photosclone/` 的数据会在启动/打开图库时自动上移到第一层（含官方「照片」图库，幂等，只移动一次）。

`database/PhotosClone.sqlite` 除 `assets` / `albums` / `folders` / `people` / `settings` 外，`assets` 还保存评分 / 旗标 / 色标、SHA-256（`content_hash`）与感知哈希（`perceptual_hash`）；`asset_analysis` 表保存端侧分析结果（场景标签、OCR 文字与归一化特征向量），`asset_overlays` 表保存官方「照片」图库照片的拾光补充元数据（收藏 / 隐藏 / 关键词 / 标题 / 查看时间 / 评分 / 旗标 / 色标；NULL 表示沿用 Apple 的值），以及跨范围派生缓存：`system_analysis`（系统图库识别 / 特征，按图库路径）、`derived_reports`（体检 / 美化推荐，按范围签名）、`cloud_assets`（网盘 EXIF / 识别 / 特征 / 查看记录，按挂载 + 路径）、`cloud_people` / `cloud_person_assets`（网盘人物聚类）。删除照片时会同步清理对应行；断开网盘时清理该挂载的 `cloud_assets` / `cloud_people` 与派生报告。

**打开哪个图库就以哪个图库为准**：图库选择器、设置里的「切换到此图库」、访达双击都算打开，会切换当前图库——展示它自己的照片、相簿、系统图库连接、网盘挂载与库级设置，新导入、编辑与设置写入它自己的 `database/PhotosClone.sqlite`；不会把上一个图库的内容搬进新打开的图库。

打开官方「照片」图库时，`Photos.sqlite` 与 Apple 自带的原图只读，拾光自己的数据（`PhotosClone.sqlite`、导入副本、缩略图、编辑结果）同样写在该库第一层 `database/`、`originals/`、`resources/` 里。侧边栏「系统图库」的连接菜单只做只读浏览，不切换当前图库。

应用支持目录（`~/Library/Application Support/PhotosClone/`）：

- `ContainerPath.txt`：上次打开的图库路径
- 旧版本地库残留目录（仅在没有图库时用于迁移提示）
- 旧版的 `SystemThumbs/` 与 `SystemLibraryCache/` 不再写入；系统图库缓存已移入各图库包内。

## 已知限制

- 官方「照片」图库、SMB 共享与阿里云盘/百度网盘为只读；仅本地图库与 WebDAV 支持写入。
- SMB 依赖 macOS 系统 NetFS 挂载，共享以系统方式挂载到 `/Volumes/<共享名>`（与 Finder「连接服务器」一致），拾光复用该挂载点读取；从侧边栏断开时自动卸载。首次「整个共享」扫描大目录需要一些时间，之后刷新会重新读取。
- 暂未实现官方的高级能力：视频修剪/慢动作变速、iCloud 共享图库、屏幕保护输出。
- 评分 / 旗标 / 色标筛选目前只接入本地图库；系统「照片」图库可写入叠加数据并展示，但索引分页筛选尚未接入。智能相簿条件也还没有这三项。
- 图库保险库只面向拾光自建图库，备份 `originals` / `database` / `resources/renders`，不复制缩略图、转码与系统图库缓存；尚未做百万级图库的真实恢复演练。
- 查重首次扫描需要读取全库文件；中断后没有持久化断点，重新进入会继续补扫未计算项。导入查重只做 SHA-256 精确匹配，相似照片不会阻止导入；RAW+JPEG / HEIC+JPEG 自动堆栈尚未实现。
- 检查更新只读取 GitHub Releases 并打开发布页，不是静默自动更新；诊断日志只在本机，未接入符号化崩溃平台。
- 回忆影片导出为无声 mp4（不含配乐）；端侧人脸聚类在本地图库与网盘各自独立：本地需要逐张分析，首次运行较慢；网盘只对当前目录做聚类且结果只存内存，切换网盘即清空；系统图库只读官方已有人物结果。
- 端侧内容分析（场景标签 / OCR / 相似照片 / 体检 / 美化推荐）的派生结果都写入当前图库的 `PhotosClone.sqlite`（系统图库 → `system_analysis` / `derived_reports`，网盘 → `cloud_assets` / `cloud_people` / `derived_reports`），不写 Apple 的 `Photos.sqlite` 与网盘；视频暂不参与，未分析的照片不会出现在「场景」「包含文字」或相似结果里。图库体检与相似检索在系统图库只检查当前已载入照片、在网盘只检查当前目录（分别最多 500 / 80 张）；智能美化在系统图库与网盘默认只生成副本并保存到拾光。系统「照片」图库作为当前图库时，编辑 / 删除 / 相簿增删改 / 收藏隐藏只经 PhotoKit（需在系统设置里授予照片读写权限），且拾光会先用样本照片校验「当前打开的就是系统照片库」，不是则拒绝写入；额外连接的系统图库与网盘仍不可写。文件夹能否通过接口管理仍需验证（设置里有验证入口）。
- 网盘 EXIF 只读取当前目录前 200 张的头部（可继续读取），HEIC 等缺少 EXIF 的文件会回退为文件修改时间；网盘地图 / 位置 / 人物 / 值得重看 / 重复项目 / 图库体检 / 相似检索都基于已读取的目录，只读展示，不修改网盘文件；美化副本写入拾光，不上传网盘。
- 导入始终拷贝原文件，不支持引用原位置。
- 视频转码依赖外部 `ffmpeg`，未安装时仅支持系统可解码的编码。
- **多图库**：最近图库与系统图库连接会同时保留并可快速切换，但同一时间只渲染一个“当前图库”的网格，不支持两个库并排显示。
- **压缩**：无损模式保持像素与尺寸不变（JPEG 仅移除元数据、其它格式转无损 PNG），体积可能不会减小；有损模式为高质量有损压缩，逐字节还原依赖「保留原图备份」。
- 「年 / 月」时间轴总览只在图库层级提供，相簿/文件夹使用普通网格。
- 大图库分页覆盖「所有照片」网格与媒体类型/收藏/隐藏等本地范围；「年 / 月」总览在超过 5000 张时同样走 SQL 分区（每年/每天最多取 4 张样本）。人物、回忆与地图仍基于内存索引，超百万张时首次进入这些页面会较慢。
- 图库元数据仍在启动时整体载入内存（分页只减少筛选/排序/复制的开销）；下一步是把常驻元数据也改为按需查询。
- HDR 设置对查看器内的静态图片生效（关闭时按 sRGB 显示）；系统级 EDR 行为仍由 macOS 决定。
