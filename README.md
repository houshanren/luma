> **拾，是拾起；光，是光影；拾光，也是时光。**
> 一张旧照片，是停住的光；一段旧视频，是流动的光；一行文字，是光落下的回声。拾光，就是把它们捡回来。
>
> 捡回来只是开始。读懂光里的人和事，串成你的时间线，再讲成一段可以留存、可以递出去的影像——这是拾光最终要去的地方。

## 下载与系统要求

**下载**：[Luma 2.2.0](https://github.com/houshanren/luma/releases/download/v2.2.0/Luma-2.2.0-macOS.zip) · [全部版本](https://github.com/houshanren/luma/releases) · [官网](http://houshanren.asia:10086/) · [源码构建](#获取与构建)<br>
**环境**：macOS 14+，Apple 芯片与 Intel 通用；FFmpeg、YOLO11n、地点库已内置，SigLIP2 按需下载。<br>
**开始拾光**：解压 → 拖进「应用程序」→ 打开，新建图库或接入系统「照片」图库。

> 发布包为本地自签、未做 Apple 公证；被 Gatekeeper 拦截时右键「打开」，或执行 `xattr -dr com.apple.quarantine /Applications/Luma.app`。完整说明见包内 `Install-README.txt`。

## 这是什么

拾光（Luma）是一款**完全本地运行**的 macOS 原生照片与媒体管理应用。

它把三件原本分裂的事放进同一个窗口：**打开你自己的图库**、**接入系统「照片」图库**、**直连网络存储与影视源**。不迁移、不上传、不需要账号——照片默认不必离开这台 Mac。

- **照片是自己的**：图库是一个标准 `.photoslibrary` 包，放在本机任意目录或外置磁盘；收藏、关键词、评分、查看时间等补充数据写在库内旁挂数据库，绝不改动 Apple 的 `Photos.sqlite` 一行。
- **界面是克制的**：对齐系统「照片」的浏览心智，年 / 月 / 所有照片、相簿、人物、场景、地点一屏可达；四种网格形式、键盘优先、深浅色与强调色即时联动。
- **能力是可选的**：图库、网络存储、网络资源、网络电视、网络影院五个模块可独立拾起或放下，侧边栏与全局搜索随之收放。
- **散落的光会收在一处**：系统「照片」、本机与外置盘、NAS 与网盘已在同一条时间线上；微信与手机里的照片视频会按同一套来源与去重规则接入（见「往更远处拾」）。
- **智能是可选、可换、可核查的**：图片理解在本机完成（Vision / SigLIP2 / YOLO），大模型可以接云端，也可以接本机的 Ollama / LM Studio；助手通过 86 个本地工具真正去检索、整理和播放，动数据前先确认，默认不上传原图。

**它的终点不是收纳，而是讲述**：把散落在各处、跨越多年的照片、视频与文字收进同一条时间线，读懂里面的人和事，再讲成一段可以留存、可以分享的时光。

## 核心能力

**浏览与整理**

- 年 / 月拼图总览、所有照片网格、相簿 / 文件夹 / 智能相簿、媒体类型与更多项目。
- 排序（日期、标题、文件名、大小、类型、相机、地点、时长）、筛选（收藏 / 已编辑 / 照片 / 视频 / 截屏 / 未加入相簿）、关键词筛选。
- 框选、方向键导航、可开关的卡片文字浮层、右键菜单作用于整个选区。
- 拖拽导入、SHA-256 查重、导入后校验；最近删除与恢复、图库级撤销 / 重做。

**端侧智能与 AI 助手**

- **本地图像理解（不上传）**：Vision 做精确 OCR、条码 / 二维码、人脸与人体姿态、文档分割与裁切，并在没有本地模型时兜底场景分类；SigLIP2 提供 249 个零样本中文标签（含 41 个轨迹标签）与 768 维图像向量，YOLO11n 补充 80 类物体（仅在 SigLIP 标签 < 2 时启用），系统 Vision 分类器同时作为第二信号，补天空 / 文档 / 截图 / 衣服等 SigLIP 欠触发概念（同样仅在标签 < 2 时启用），Photos 导入的截图再用「屏幕比例 + 文字 + 无相机信息」兜底；结果写入当前图库，用于场景页、关键词、相似照片与全文搜索，并融合成「活动 / 轨迹片段」进入地点详情。
- **视频也打标（不上传）**：按视频时长均匀抽 4–6 帧（5%–95%，0.25s 容差；取帧失败退回 ffmpeg 同时刻），复用照片管线后聚合：标签需出现在至少 1/3 帧，OCR 去重合并，向量取平均归一化。
- **本地模型可按需安装**：SigLIP2 约 350MB（图像编码器 92MB + 文本编码器 259MB），从国内镜像下载、SHA-256 校验、编译成 Core ML 后原子替换，失败自动回滚；支持从本地目录离线导入、随时停用或删除。未安装或旧系统上自动回退 Apple Vision，不会让功能整块消失。本地视觉模型 Qwen2.5-VL 3B（约 2.8GB）与 Qwen3-VL 4B / 8B 同样可一键安装，只在本机推理。
- **大模型可云端、可本机**：预置 DeepSeek / Kimi / GLM / 通义千问 / 豆包 / OpenAI 与任意 OpenAI 兼容端点；也可以一键探测本机的 Ollama、LM Studio，模型自己选，数据不出本机。API Key 只进钥匙串。
- **Agent 真的会做事**：86 个本地工具覆盖图库检索、相册 / 文件夹、评分 / 关键词 / 标题、压缩 / 美化、删除恢复，以及影院刮削匹配、网络资源、网络影院与电视直播；支持快速 / 标准 / 深度三档、多轮工具调用、执行轨迹与失败回传。
- **动手前先问一句**：37 个写工具按「每次确认 / 仅高风险 / 自动应用」审批，一次回复里的多个动作合并成一个确认框；有操作意图但模型没调用工具时，会明确提示「本次没有执行」，不接受口头完成。
- **图片默认不出本机**：默认只把元数据与本地标签 / OCR 发给模型；要发原图需要手动开启，开启后也只会发送长边 1024 的 JPEG，默认最多 4 张。
- 还有：人物聚类、地点聚类与「地点 + 连续日期」行程段，模糊 / 大视频 / 相似照片体检，以及「画面统计 → 调整理由」的本地美化建议。

> 当前边界：内置 GGUF 本地语言模型尚未接入（用 Ollama / LM Studio 代替）；技能与连接器是本地内置清单，没有远程市场；多 Agent 只做「角色 + 只读委派」，不做后台自治与无人值守写操作。
>
> 与 ChatGPT / Claude / Gemini / Copilot / Perplexity / Manus / Kimi / 豆包 的横向对比、人在回路与安全边界，以及 Luma 2.2 的五个 P0，见 [AI 助手横向对比与 2.2 能力基线](docs/ai/luma-ai-assistant-competitive-analysis-2026-11.md)（[视觉版](docs/ai/luma-ai-assistant-competitive-analysis-2026-11.html)）。

**观看与输出**

- 窗口内查看器与全屏查看器共用一套翻页、缩放、胶片条与元数据面板。
- 自研播放内核：HDR、倍速不变调、多音轨即时切换、字幕、按片源帧率匹配刷新率；按住快进 / 快退逐级加速。
- 编辑、批量压缩导出、打印、幻灯片与回忆影片。

**搜索**

- 统一搜索覆盖图库、网盘、影院、网络影院、电视、资源六个来源，结果按来源与类型分组；模块关闭后对应来源胶囊与结果一起消失。
- 图库来源同时匹配文件名、标题、相簿 / 文件夹、官方关键词、端侧场景标签与 OCR 文本；百万级图库从索引取全量命中，不做条数截断。

### 影视墙

「影院」指本地 / 网盘影片的刮削海报墙；「网络影院」指影视源聚合。两者共用同一个播放器。

| 能力 | 适用 | 状态 | 当前实现 |
| --- | --- | :---: | --- |

| 能力 | 状态 | 当前实现 |
| --- | :---: | --- |
| 片源接入 | ● | 本地、SMB、WebDAV、网盘直链、影视源、直播；远端 Range 代理按 4 / 8 / 16MB 分块预取 |

| 多音轨 | ◐ | 一次 HLS 会话装多轨，切换即时生效；HDR / 转码场景只能重建流 |
| 声道策略 | ● | 默认保持原样，可手动降混立体声；音频延迟 ±2 秒且不丢同步 |

| 字幕偏好 | ● | 简体 > 繁体 > 中文 > 英语；识别 forced / default；外挂与内嵌候选统一排序；按影片记住手动选择；±0.5 秒偏移 |

| 快进快退 | ● | 单次步长 1–30 秒；连按或按住按 1 → 2 → 3 → 4 → 6 → 8 倍加速，单次上限 10 分钟 |
| 画面 | ● | 适应 / 填充 / 拉伸 / 原始像素；16:9 / 4:3 / 2.35:1 / 1:1 预设与平移；旋转 |

| 进度条预览 | ● | 悬停或拖动取对应时间点画面，采样间隔随片长自适应 |

**播放决策链**（代码里的实际分支）

| 顺序 | 触发条件 | 处理 |
| --- | --- | --- |
| ① 原生直读 | 本地 / 网盘资产、系统可解码、非隔行、非 4K50-60 HEVC、不需要 HDR 映射、未烧录字幕 | AVPlayer 直接播放原文件，起播最快 |
| ② 无损转封装 | 容器不受系统支持（MKV / AVI / TS…）但视频轨可解码 | ffmpeg 边下边转 fMP4 HLS，视频流原样拷贝；HEVC 写 `hvc1`，杜比视界保留 `dvh1` / `dvhe` |

| 直播 | HLS 直接交给 AVPlayer；非 HLS 由 ffmpeg 转封装 | 断线重连、就绪线路记忆、失败最多三轮顺延 |


### AI 与本地推理

| --- | :---: | --- |
| 场景 / 物体标签 | ● | SigLIP2 零样本中文标签（249 个，含 41 个轨迹标签）+ Apple Vision 分类器第二信号（补天空 / 文档 / 截图 / 服饰等欠触发）+ YOLO11n（COCO 80 类，置信度 0.4）补充主体；模型未装时回退 Vision 分类（取 top 20） |

#### 开 / 不开本地模型的区别

本地模型默认关闭，两个开关都在「设置 › 本地模型」。关闭只是停用，不删文件；照片信息面板会直接标注当前标签来自哪个模型。

| 能力 | 开启本地模型 | 关闭本地模型 |
| --- | --- | --- |
| 画面标签 | SigLIP2：**249 个中文标签**（含 41 个轨迹标签），按阈值 + 组内限额输出；YOLO 物体也只在标签 < 2 时补 | 退回系统 Vision 分类：少量粗粒度中文标签（人物 / 儿童 / 文档 / 截图 / 天空 / 树…）+ 英文概念；没有 249 标签体系 |
| 场景 / 轨迹融合 | 标签 → 活动 → 轨迹片段 | 规则仍运行，但可用标签变少，活动与轨迹命中明显下降 |
| 相似照片 / 以图搜图 | 768 维 SigLIP 向量，同一模型分析的库内可互相比 | 退回 Vision FeaturePrint（2,048 维）：能用，但与 SigLIP 向量不互通，混用库只匹配同一来源的照片 |
| 语义搜索扩展 | SigLIP 文本塔把查询映射到标签空间 | 只能关键词命中，不做同义扩展 |
| 本地语言模型（对话 / 看图 / 起名 / 诊断） | Qwen2.5-VL 3B / Qwen3-VL 4B / 8B 离线可用：助手对话与看图、体检解读、起名与分享文案、关键词整理、地点补全、搜索改写、频道清洗、影院兜底、事件三元组 | 助手需接云端 API；这些一次性任务退回规则或模板，不静默失败 |
| 隐私与体积 | 全本机推理；SigLIP2 约 355 MB，Qwen 另占 2.8–6.2 GB | 不占模型体积；Vision 仍在本机运行，不上传 |

关闭 SigLIP2 后照片不会写入分析版本标记，重新开启时这些照片会自动补扫；开着模型但结果来自旧版本时，也会按版本标记补扫。

## 往更远处拾

拾光走过的路，一直是同一件事：把光拾起来。过去拾的是硬盘里已经存下的——系统照片库、本机与外置盘、NAS 与网盘、影视源；现在开始读懂光里有什么；再往后，是把你自己的拾光讲出来。收拢、读懂、讲述，是同一件事的三段，不是三件并列的功能。

| 阶段 | 已经具备 | 在路上 |
| --- | --- | --- |
| **收拢** | 系统照片、本机 / 外置盘、NAS、网盘、影视源 | 本地微信、手机微信、手机相册 |
| **读懂** | 照片的场景 / 物体 / OCR / 人物 / 向量 | 视频抽帧理解 |
| **讲述** | 时间轴、人物、地点、行程、回忆影片、幻灯片、足迹回放、导出与分享 | 主题自动成章、AI 剪辑 / 配乐 / 旁白 / 字幕、主题短片与链接分享 |

**收拢 · 把微信和手机里的光接进来。** 本地微信走文件层只读扫描，导入聊天里保存过的图片与视频；手机端微信先「保存到相册」，再由手机相册作为只读挂载源接入，原图默认留在手机，查看高清、播放与编辑时才按需回源。三条来源与图库共用同一套规则：SHA-256 加感知哈希去重，同一张照片在微信、相册、网盘各出现一次，时间线只留一行，详情页注明「来自几处」；移除来源只撤来源记录，不连坐已归档的原件。不解析聊天记录、不复原发送者，也不回写微信。

**读懂 · 让视频也能被理解。** 照片的端侧理解已经落地，视频目前只有封面与进度缩略图。规划中的抽帧理解会按镜头切分与等间隔取关键帧，逐帧跑同一套端侧模型，再把结果折回整段视频：于是「海边」「烟花」「孩子在跑」不只搜得到照片，也搜得到那段视频，视频同样进入场景页、智能相簿与「值得重看」。抽帧只在本机进行，帧不外发。

**讲述 · 把自己的拾光讲出来。** 先梳理：同一条时间线按年 / 月、人物、地点、行程与主题收束成段落，这部分已经可用。再生成：回忆影片已可导出（1280 × 720 / 24fps），幻灯片与足迹回放也已具备；规划中的是让 AI 参与选帧、剪辑、配乐、旁白与字幕，把「生成一段视频」从手工拼装变成一句话的事。最后是制作与分享：成片、相册与「值得重看」现在能导出、打印、用系统分享，规划中的是主题短片、可分享链接与家庭共享。

> 上表「在路上」的部分尚未进入当前版本，不计入上文能力矩阵的 ●；设计稿与边界见 [拾光屋架构](docs/architecture/shiguang-house-2026-11.md)。

拾光不替你决定哪一段值得留下，它只是把散落的光收拢、读懂、串好，再交回你手里。

## 设计语言

拾光的视觉从一句品牌隐喻长出来：**被拾起的光**。

- 品牌色是一段暖到冷的光谱：琥珀 → 珊瑚 → 粉 → 紫 → 青，用于图标光环、标题渐变与装饰线条。
- 强调色提供 11 种选择（系统 / 蓝 / 靛蓝 / 紫 / 粉 / 橙 / 金 / 绿 / 薄荷 / 青 / 石墨），并自动为浅色强调配深色前景。
- 主题（外观 + 强调色）**按图库保存**：切到另一个图库，界面跟着换一套光。
- 首次建库的引导页即是一场品牌叙事：外观弧、强调色光点与「拾光」徽标围成一圈年轮，下方是「历史 → 此刻 → 未来」的光线。

细化的色板、字号、间距、组件与动效规范见 [UI 设计及标准](docs/ui-design-system.md)。AI 助手的右侧 Inspector、上下文胶囊与计划 / 审批卡见 [AI Inspector 界面设计](docs/design/luma-ai-inspector-2026-11.html)。

## 技术架构

| 层 | 目标 | 职责 |
| --- | --- | --- |
| `LumaCore` | 无 UI 依赖 | 网格布局算法、缩略图档位、感知哈希、美化建议 |
| `PlaybackCore` | 播放内核 | 时间轴、片源计划、AVPlayer 引擎、ffmpeg 管道、字幕解析 |
| `LumaContentCore` | 内容契约 | 源、内容引用、播放目标、搜索、任务、错误与进度接口 |
| `Luma` | 应用 | SwiftUI + AppKit 界面，状态树、服务层与各模块实现 |

- 纯 SwiftPM，零第三方依赖；macOS 14+，链接系统 `libsqlite3`、`Photos`、`NetFS`。
- 数据层：自有 `MetadataStore`（SQLite）+ 系统图库只读索引 `SystemIndex`（直连 `Photos.sqlite`）。
- 大图库不为视图层 `filter` / `sorted`：范围、筛选、排序下推 SQLite，按 600 张一页的窗口滚动加载。
- 并发模型：主线程只跑界面与状态，扫描、索引、解码、网络请求在后台任务里完成。
- AI：端侧 `Vision` + Core ML（SigLIP2 / YOLO11n）负责图像理解；`AIChatProvider` 走 OpenAI 兼容协议，`AIToolRegistry` 按模块注册 86 个工具。
- AI 结果只写补充数据：本地库 `asset_analysis`、系统库 `system_analysis`、网盘 `cloud_assets`；模型安装在应用目录，API Key 只进钥匙串，都不进图库、不改原图。

构建、目录结构、数据模型、查询与打包流程见 [代码开发文档](docs/development.md)。

## 获取与构建

**从源码构建**：需要 macOS 14 Sonoma 及以上，以及 Xcode 15+ / Swift 5.9 工具链。

```sh
# 构建（默认 release），产物 Luma.app
./build.sh

# 只做增量编译并重启 App（改界面时最快，几秒到一分钟）
./build.sh preview

# 纯逻辑断言检查（命令行工具链没有 XCTest）
swift run LumaCoreChecks
```

**测试集与产品截图（Agent 入口）**

```sh
python3 Tools/testkit/testkit.py dataset      # 一家四口 2010–2026：56 张照片 / 17 个视频 / 网盘 / 影院 / 资源 / 电视测试集
python3 Tools/testkit/testkit.py dataset --photos 5000   # 规模模式：5000 张照片，按年份分相簿
python3 Tools/testkit/testkit.py serve        # WebDAV + 苹果CMS + 图集站 + HLS + EPG mock
python3 Tools/testkit/testkit.py screens      # 真实界面逐页截图（先 ./build.sh debug）
python3 Tools/testkit/testkit.py perf         # 视频性能基线
python3 Tools/testkit/testkit.py regression   # 校验 + Swift 断言（--with-ui 含截图）
```

产物写 `~/Movies/LumaTestKit`，不提交。页面 id、建议图注与 AI 写文档的引用方式见 [Tools/testkit/README.md](Tools/testkit/README.md)；截图清单在 [screens.json](Tools/testkit/screens/screens.json)，应用内入口在 [TestKitHarness.swift](Sources/Luma/Services/App/TestKitHarness.swift)。

首次启动会进入建库引导：新建一个拾光图库，或接入已有系统「照片」图库；也可以选择把旧版本地照片迁入。之后每次启动自动打开上次使用的图库。按住 **Option** 启动可先打开「选取图库」面板（或 `⌥⌘O`）。

发布包当前为本地自签（`Luma Local Dev`）、未做 Apple 公证；设置 `CODESIGN_IDENTITY` / `PACKAGE=1` / `NOTARIZE=1` 可走完整的签名、打包与公证流程。
