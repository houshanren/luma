判断一：模型不是瓶颈，编排是瓶颈。同一个模型，给 86 个工具裸奔，和给 12 个相关工具 + 计划 + 上下文胶囊，任务成功率会差一个档位。
判断二：86 个工具是资产，也是负债。工具越多，单轮选择越容易错；需要「领域 → 意图 → 工具组」的渐进披露。
判断三：安全边界已经领先，但还不可证明。默认不发原图、Key 进钥匙串是优势；2.2 已补审计日志与注入提醒，连接器做了环境隔离。OS 级沙箱与完整注入过滤仍缺。
判断四：人在回路要从「弹窗」升级为「协作」。计划审批 + diff + 检查点 + 接管，才让用户敢于放权。

六项真实优势

  • 跨模块可执行：从检索到整理到播放，竞品很少有同样的本地动作面。
  • 默认数据最小化：只发元数据、本地标签与 OCR。
  • 写前确认 + 合并弹窗：一轮一次，比逐工具弹窗克制。
  • 防假完成：未调用工具会被要求重试，仍不执行则明确报错。
  • 上下文是对象：范围、选中、搜索现场、影院快照分别组装。
  • 本地模型可换：Ollama / LM Studio + 18 家云端。

2.1 时的十个关键缺口 · 2.2 现状

  • 已补 非流式 → 逐字流式 + 思考摘要 + token 用量。
  • 已补 无计划卡 → 模型生成计划卡，可改可批可取消。
  • 已补 无检查点 → 任务级检查点，一键撤销本轮写入（含影院）。
  • 已补 无成果物 → 成果物库：搜索 / 类型筛选 / 打开 / 移除。
  • 已补 83 工具全量暴露 → 领域 → 意图 → 工具组渐进披露。
  • 已补 审批无 diff → 字段级 diff + 逐条取舍。
  • 已补 无长期记忆 / 语音 / 指认 / 连接器 → 全部落地（语音仅输入）。
  • 部分 无审计与注入防护 → 审计日志已落盘；注入是「规则 + 可疑检测」，不是完整过滤。
  • 部分 无沙箱 / 成本 → 连接器做了环境变量白名单 + 固定工作目录；成本只到 token 级。
  • 部分 无并行 / 追问 / 编辑重发 → 已补；仍缺「多分支对话树」。
一个真实任务的时间线：用户说「整理当前影院里未识别的影片」→ 界面只显示「正在理解当前范围」→ 模型连续调用目录树、候选搜索、批量写回 → 写操作合并成一个确认框，只列前 8 条 → 用户点允许 → 等待 → 一次性返回总结卡。结果不差，但过程不可见、不可改、不可退。

04 · Product Notes

04十个产品，十种可借鉴的做法

只提炼对拾光 2.2 有用的部分，不做产品评测。

ChatGPT

通用助手的事实标准

单列对话 + Canvas + Projects + Memory + Agent + Tasks。对话与成果物分成两个面，用户可以在成果物上继续编辑。

学什么：成果物画布；流式 + 思考摘要；可编辑重发。
别照搬：通用浏览器 Agent 会稀释「私人图库」定位。

Claude

可连接、可审阅的工作台

Artifacts 侧栏、MCP、Skills、Computer Use、Claude Code 权限模式。工具调用以可展开卡片呈现，计划模式先读后写。

学什么：权限模式是一等公民：手动 / 接受编辑 / 计划 / 自动。
别照搬：MCP 配置门槛高；拾光应做成可选、可解释、默认关闭。

Gemini

系统级多模态助手

Live、Deep Research、Canvas、Gems、Workspace 与个人上下文。语音与相机是第一入口，文本是补充。

学什么：上下文获取是产品能力，不是提示词技巧。
别照搬：拾光没有 Google 生态，不追求全生活助理。

Microsoft 365 Copilot

企业工作流助手

Graph grounding、Office 内嵌、Researcher / Analyst、Copilot Studio。引用密集、可追溯到文件与邮件，权限、审计、DLP 完整。

学什么：企业 Agent 的核心不是能力，是权限、审计与可追溯。
别照搬：企业权限模型太重；拾光用「轻量审计 + 本地可见」替代。

Perplexity

答案引擎

搜索即产品；每个回答默认带编号来源；Spaces 沉淀主题；Deep Research 做长报告；Comet 做浏览器 Agent。

学什么：引用不是装饰，是信任机制。
别照搬：「答案优先」不适合本地操作任务；拾光要「动作优先」。

Manus

通用任务 Agent

任务视图 + 计划 / 待办 + 「Manus 的电脑」实时画面 + 交付卡 + 接管。过程可见，交付物是文件而不是一段话。

学什么：长任务的心智是「任务」，不是「消息」。
别照搬：云端 VM 不适合拾光；拾光的 VM 是本地图库与播放器。

Kimi / 豆包 / 通义 / 智谱

国内助手的四种路径

Kimi 长上下文与任务成果物；豆包多模态与语音；通义模型 + 云 + 钉钉 / 夸克；智谱 AutoGLM 操作 Agent。共同点是中文强、OpenAI 兼容度高。

学什么：中文任务型对话的文案与节奏；成果物卡片比纯文本更像「交付」。
别照搬：内容消费与娱乐化会稀释「私人图库」定位。

Apple Intelligence / Siri

系统级隐私标杆

端侧 + Private Cloud Compute + App Intents + 屏幕感知；复杂任务转交外部模型需要用户授权。

学什么：隐私不是口号，是架构。
别照搬：没有系统权限与 App Intents 生态，拾光应做「应用内系统」。

Google Photos / Lightroom / Immich

影像垂直的 AI 形态

Ask Photos 做自然语言检索与解释；Lightroom 做「建议 → 预览 → 应用」；Immich 做本地索引 + 自托管。

学什么：照片 AI 的竞争点是「安全地找到并处理一批照片」，不是闲聊。
别照搬：云端语义检索不可复制；拾光应把端侧标签与索引做到极致。

Cursor / Claude Code / Codex

Agent 工作台的最佳作业

计划模式 + 逐文件 diff + Keep / Undo + checkpoint + 权限提示 + 终端输出。先计划，后动手，是可回滚的默认。

学什么：把「照片 / 相簿 / 影院条目」当文件，把「写操作」当编辑，就需要 diff、checkpoint、undo。
别照搬：终端与仓库概念不适用；拾光的仓库是图库。
05 · Blueprint

05Luma 2.2：从「会聊」到「会做完」

P0 与 P1 体验层已落地；不做多 Agent 与后台自治。
一句话，把图库和影院里的事做完；
而且看得见、改得动、退得回、留得下。
2026-11-28 落地：流式、计划卡、字段级 diff、任务级检查点（含影院）、接管、成果物库、上下文胶囊、工具路由、长期记忆、语音、MCP 客户端、指认、技能库、连接器预设、定时任务、角色与只读子 Agent 委派均已进入代码。界面原型见 AI Inspector 界面设计。
本地优先过程可见计划先行 可逆优先风险分级成果物化 渐进披露可解释可审计
1

流式输出与工具时间线

问题：整段返回，长任务只有一句活动文案。
方案：SSE 流 + 工具事件实时追加；保留非流式回退。
首字 < 1.5s · 每步 300ms 内可见
2

计划卡

问题：多步任务直接执行，用户不知道要做几步。
方案：结构化计划（步骤 / 工具 / 影响 / 风险），可改可删可批。
≥ 2 步任务 100% 先出计划
3

检查点与撤销

问题：只能事前确认，不能事后回滚。
方案：操作日志 + 逆操作 + 任务级检查点。
可逆写 100% 可撤销 · 成功率 > 99%
4

审批 2.0

问题：三档审批，没有 diff，不知道改哪 12 项。
方案：L0–L3 风险分级 + 明细 + diff + 本次都允许。
破坏性操作 100% 有明细 · 确认 ≤ 1.2 次
5

成果物

问题：对话结束只剩聊天记录。
方案：相簿 / 片单 / 清单 / 报告 / 回忆影片作为成果物卡。
每类任务至少一种成果物
6

上下文胶囊

问题：上下文隐式，用户不知道模型看到了什么。
方案：范围 / 选中 / 搜索 / 影院 / 时间点做成可见胶囊。
可固定 · 可移除 · 可 @ 引用
7

工具分层与意图路由

问题：86 个工具全量暴露，选择错误率高。
方案：领域 → 意图 → 工具组；单轮最多 24 个。
选择准确率 > 90% · 平均暴露 ≤ 18
8

错误与假完成防护 2.0

问题：错误只有一段红字，不知道该重试还是换方案。
方案：结构化错误码 + 可操作错误卡；保留防假完成。
30 条对抗提示零假完成

P1 · 2.3

  • 记忆分层：会话摘要 / 图库偏好 / 长期习惯，全本地、可编辑。
  • 语音与指认：按住说话；@这张照片、@12:34。
  • 连接器 / MCP / Skills：可选、默认关闭、权限清单、沙箱、审计。
  • 后台与定时：体检、刮削队列、今日日报、追更提醒。
  • 可观测性：成功率、错误率、延迟、审批率、token / 成本。

P2 · 3.0

  • 模型路由：按任务选模型与预算；本地回退。
  • 多 Agent：馆员 / 策展 / 影院管理员，串行编排、预算与人工闸门。
  • 不做：通用聊天、写作、编程；社交与内容平台；云账户；无人值守高风险操作。
多 Agent 的前提是 P0 的计划、检查点、审计先落地；否则只会放大不可控。

07从「有边界」到「可证明」

级别定义示例默认策略

L1可逆写评分、旗标、色标、关键词、标题、相簿加入 / 移出、收藏自动 + 撤销入口

威胁模型

  • 提示词注入：OCR、文件名、NFO、网页源、MCP 返回；需要输入隔离标记与可疑指令过滤。
  • 数据外泄：原图、路径、Key；需要网络请求审计与字段级脱敏。
  • 破坏性操作：删除、压缩、批量刮削；需要 diff、检查点、撤销。
  • 供应链：MCP / Skills / 第三方源；需要清单、权限声明、沙箱、默认关闭。
  • 混淆代理：外部内容诱导模型调用工具；需要来源标记与跨源指令拒绝。
  • 假完成：模型声称完成；需要工具回执必填与结果校验。

五个反模式

  1. 把「工具数量」当卖点，而不是「任务成功率」。
  2. 用「自动应用」换短期爽感，牺牲可逆与信任。

  4. 用「AI 说完成了」代替「工具回执 + 结果校验」。
  5. 把成果物做成聊天记录截图，而不是可继续编辑的对象。
