控制台：把「⋯ 下拉」换成一块面板

为什么要换

创意工坊：技能是「怎么说」，连接器是「能接什么」

技能

780×660 双列卡片：搜索框 + 领域胶囊（全部 / 图库 / 影院 / 电视 / 跨模块）。每张卡显示图标、标题、领域、「会修改」标记与一句摘要，底部「填入」「执行」。任务描述可复用，执行仍走计划 / 审批 / 撤销。

连接器（MCP）

同一面板内分段切换。每个预设是一张卡：命令、摘要、需要目录时给「选择…」；已添加显示绿标，不重复安装。默认不启用，写入 mcp.json 后重载，工具调用每次确认。

一致性

控制台、创意工坊、设置页三处指向同一份数据：AISkillLibrary、AIConnectorMarket、MCPService。不出现「这里能加、那里看不到」的第二套列表。

对话内的六个新动作：改一句、问一句、看一眼、记一次

编辑重发

最后一条 user 气泡 hover 出「编辑」。点开后截断这条消息及其后回复，原文回填输入框并聚焦；不适合改历史轮次，避免误删上下文。气泡旁写明「会清空其后的 N 条回复」。

主动追问卡

模型信息不足时调 ask_user，在输入框上方浮出一张问卡：一个问题 + 2–4 个选项 + 「其他」自由输入。回答后继续原任务；后台任务禁用，避免无人值守挂起。

思考过程折叠

推理模型返回的 reasoning 收在回答上方一行「思考过程 · Ns」，默认折叠；流式中显示「正在思考…」。展开是灰底小字，不与正文抢层级。

始终允许

审批卡四档：本次都允许 / 始终允许 / 允许 / 取消。只对可逆写开放；高风险与 mcp__ 外部工具不出现「始终允许」。记住的清单在控制台「角色与审批」卡里可一键清除。

token 尾注

每条回答底部小字 1,240 tok（prompt + completion）；控制台「会话」卡显示 in / out。端点不返回 usage 时显示「端点未返回」，不猜。

成果物库与任务中心

成果物条末尾「全部 N 个成果物 →」打开 780×640 库：分类计数、搜索、类型胶囊、双列卡、打开 / 移除（只删记录不删相簿）。任务中心 560×560：顶部一行「验收」（成功率 / 首字中位 / 审批均值 / 平均 token + schema 节省），下面是运行中实时走秒与最近 20 条。

02 · Integration

02跟现有界面的十一个接力点

不是把 AI 塞进一个孤立面板，而是让它接住用户已经在做的事。

选中即问

Gallery → Selection → Inspector

选中 3 项后，胶囊显示「选中 3 项」，候选照片优先取选中；一句话就能说「这组」。

搜索结果续问

Search → Overview → Inspector

搜索词、总数与各来源计数进入上下文；可以接着问「这批结果里哪些是视频」。

影院一键整理

Cinema Toolbar → Inspector

原来弹大窗的「一键智能整理」，现在直接打开侧栏并发出整理指令，电影画面不离开。

查看器指认

Viewer → Context Capsule

胶囊显示「正在看照片 / 视频 + 文件名」，回答可以引用当前对象，不用再描述是哪一张。

成果物回流

Artifact → Album / Trash / Cinema

相簿、清理清单、影院报告都有「打开」动作，直接回到对应模块，而不是留在聊天里。

随时接管

Running → Takeover → Resume / End

工具之间暂停，用户先去别的模块处理；完成后继续或结束，已完成的步骤仍有检查点。

任务级撤销

Result Card → Undo Journal

结果卡底部「撤销本次修改」，按任务回滚相簿、字段、最近删除与影院整组状态。

内容卡回流

Tool Result → Poster / Photo Card

影院海报、资源与频道横卡、带评分的照片卡都在回答里直接出现，点击回到对应模块。

指认 @ 对象

Composer → Mention Picker → Capsule

输入 @ 选照片，视频可一键指认当前 mm:ss；指认变成胶囊与提示词，发送后清空。

技能与定时

Menu → Skill / Schedule Sheet

10 个技能一键填入或执行；每天 / 每周定时跑只读任务，写操作停下等人。
