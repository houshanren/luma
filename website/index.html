每个 .photoslibrary 都是一等公民。库可以放在任何文件夹、外置磁盘或 NAS 上，所有数据都写入库内 —— 换机、归档、备份，只是移动一个文件夹。

网络存储

把 NAS 当成图库浏览：优先服务端缩略图，WebDAV 只读取文件头 256KB，SMB 直接复用系统挂载点。凭据只进钥匙串。

  • WebDAV 支持上传、重命名、新建与删除
  • SMB / 云盘只读浏览与播放

端侧智能 · 完全离线

它真的「看得懂」
你的照片。

场景分类、图内文字识别与图像特征向量，全部由 Vision 在本机完成。结果只写进当前图库的 asset_analysis 表，不联网、不上传、不需要账号。

  • 场景标签人物、动物、自然风景、食物、建筑、交通、室内、文档、夜景与活动，自动聚合成可点击的场景库。
  • 自然语言搜索时间词、类型、人物与场景自由组合：「2024年5月 日落」「上个月 小猫」「去年 海边 狗」。
  • 相似照片按特征向量余弦相似度找同场景、同构图，连拍与重复一次看清。
  • OCR 图内文字中英文识别后落库，可浏览所有「包含文字」的照片，也能直接输入文字定位。

与 macOS「照片」相比

不是替代。
是把缺失的那一层补上。

拾光尊重系统「照片」的位置：iCloud 同步、共享图库与系统级集成继续交给它。拾光负责它做不到的部分 —— 任意图库、超大图库、网络存储、可检查的端侧索引与可带走的内存。

隐私，是架构而不是承诺

默认，你的照片
不离开这台 Mac。

没有账号、没有遥测。端侧分析默认离线；可选的智能助手只有在你配置 API Key 后，才会把当前范围摘要（或你显式开启的压缩图）发送给你选择的模型。

0

张照片默认上传

场景、OCR 与特征向量由 Vision 在本机计算，分析结果只写入当前图库的 asset_analysis。智能助手默认也不发送图片，只在显式开启图片理解时发送压缩缩略图。

1

个本地数据库

元数据只有一份真源：图库内的 PhotosClone.sqlite。删除记录时同步清理原图、缩略图、渲染与转码缓存。

100%

断网可用

断网状态下依然可以分析场景、识别文字、查找相似与自然语言搜索。云端助手是独立的可选功能，关闭时不发送任何数据。

0

个第三方依赖

SwiftUI + AppKit + Core Image + AVFoundation + Vision + 系统 SQLite。没有 SDK、没有统计组件、没有自动更新器。

网盘密码、OAuth token 与智能助手 API Key 只存放在 macOS 钥匙串；SMB 密码不会进入命令行、环境变量或日志。
