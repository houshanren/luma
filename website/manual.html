01产品概览

拾光（Luma）是一个 macOS 原生照片管理应用，使用 SwiftUI + SQLite 构建。界面与交互对齐系统「照片」，并额外提供网络存储（SMB / WebDAV / 阿里云盘 / 百度网盘）与官方「照片」图库接入。

适合谁

照片在本地或 NAS 上、数量从几千到上百万；希望用键盘与文件系统管理照片；不愿意把图库交给云端账号。

不适合谁

依赖 iCloud 跨设备同步、共享图库、视频修剪与屏幕保护输出。这些能力继续使用系统「照片」更合适。

核心原则

图库是一个可移动的文件夹；所有元数据只有一份真源；只读来源绝不写入；端侧智能默认完全在本机完成，云端助手需要显式配置才会启用。

界面结构

左侧为图库范围（拾光 / 系统图库 / 网络存储），中间是网格，右侧或浮层是信息与编辑。查看器覆盖在网格之上。

能力地图

图库任意位置 .photoslibrary、多库切换、外置磁盘、官方图库接入 浏览年 / 月 / 所有照片、四种显示形式、大图库分页、查看器 组织多级相簿、智能相簿、封面、拖拽排序、人物、重复项目、体检 智能场景标签、OCR、自然语言搜索、相似照片，全部端侧 智能助手可选云端模型、自带 API Key、问答检索与整理操作 重温回忆影片、那年今日、旅行故事线、足迹回放 编辑非破坏调整、RAW 解码、实况照片、批量更改、导出与压缩 网络SMB / WebDAV / 阿里云盘 / 百度网盘 / AList 隐私默认不上传、钥匙串凭据、本地数据库、无遥测
阅读约定

⌘ 表示 Command，⌥ 表示 Option，⇧ 表示 Shift。文中「当前图库」指应用此刻打开的那个 .photoslibrary；「只读来源」指系统「照片」图库、SMB 共享与云盘。

02开始使用

拾光没有安装器，也没有后台服务。构建产出一份 Luma.app，双击即可运行；所有数据都写在你选择的图库里。

下载现成版本

不想自己编译，可以直接下载发布产物：Luma-1.0.0-macOS.zip（约 5 MB）。解压后把 Luma.app 拖进「应用程序」即可。

产物为 ad-hoc 签名、未做 Apple 公证，首次打开如提示“无法验证开发者”，请右键点击 Luma.app → 「打开」，或执行：

xattr -dr com.apple.quarantine /Applications/Luma.app

全部版本与源码见 GitHub：Releases · 仓库。

系统要求

操作系统macOS 14 Sonoma 或更高
开发工具Xcode 15+ 或 Swift 5.9 工具链
构建方式SwiftPM（Package.swift），无第三方依赖
产物仓库根目录的 Luma.app（可执行文件 Luma）

构建与运行

./build.sh debug     # 日常开发构建
./build.sh           # release 构建
open Luma.app        # 运行

纯逻辑检查（网格布局、缩略图档位、旅行分段）使用断言可执行目标：

swift run LumaCoreChecks

构建脚本会执行 swift build，把可执行文件、Resources/Info.plist 与 Resources/AppIcon.icns 组装成 Luma.app，并做 ad-hoc 签名。

第一次启动

  1. 没有图库时：主界面被建库门禁挡住，只显示引导页。此时不会在固定位置创建任何数据。
  2. 新建图库：选择任意文件夹（可在桌面、外置磁盘或 NAS 挂载点），命名后生成一个 .photoslibrary 包。
  3. 打开已有图库：选择拾光图库，或直接打开官方「照片」图库。
  4. 以后启动：自动打开上次使用的图库；路径记录在 Application Support/PhotosClone/ContainerPath.txt。
  5. 临时切换：按住 Option 启动应用，先弹出「选取图库」面板。

打开、切换与最近图库

操作入口说明
打开图库⌘O / 文件 › 打开图库…打开任意位置的 .photoslibrary，立即成为当前图库
选取图库⌥⌘O / 按住 Option 启动面板列出当前图库、最近打开与 ~/图片 下的所有图库
新建图库⌥⇧⌘N / 文件 › 新建图库…生成新的空图库并切换过去
切换图库设置 › 图库 › 最近使用的图库一键「切换到此图库」；不会搬运内容
切换的含义

打开哪个图库就以哪个图库为准：展示它自己的照片、相簿、设置与系统图库连接。导入、编辑与设置写入它自己的 database/PhotosClone.sqlite，不会把上一个图库的内容搬进来。只有建库引导里的「迁入旧库」才会迁移数据。

应用支持目录

ContainerPath.txt上次打开的图库路径（当前图库的唯一真源）
旧版本地库残留仅在没有图库时用于迁移提示；旧版 SystemThumbs/ 与 SystemLibraryCache/ 不再写入

系统图库缩略图与扫描索引现在写在当前图库包内的 resources/system-thumbs/ 与 resources/system-cache/。应用支持目录位于 ~/Library/Application Support/PhotosClone/，清理缓存不会影响图库本身。

建议的第一次整理

  1. 新建或打开一个图库，设置 › 浏览里选好缩略图尺寸与显示形式。
  2. 把照片拖进窗口，或按 ⌘I 导入；上千张可以分批，导入会并发拷贝并增量落盘。
  3. 重复项目检测（侧边栏「更多项目 › 重复项目」）先合并明显重复。
  4. 「场景 › 分析照片内容…」跑一次端侧分析；需要人物时再运行本地人脸聚类。
  5. 「图库体检」扫一轮，处理模糊、相似连拍与过大视频。所有删除都先进最近删除。

03图库与数据

图库就是一个 .photoslibrary 包。所有图库（自建库与直接打开的官方「照片」图库）的数据都写入包内第一层，因此备份、归档与换机都只是复制一个文件夹。

图库结构

我的图库.photoslibrary/
├── database/PhotosClone.sqlite        # 元数据唯一真源
├── originals/<首字符>/<uuid>.<ext>    # 原图副本
├── resources/derivatives/             # 缩略图
├── resources/renders/                 # 编辑渲染结果
├── resources/transcodes/              # 视频转码缓存
├── resources/backups/                 # 压缩前备份
├── resources/system-thumbs/           # 系统图库缩略图缓存
├── resources/system-cache/            # 系统图库扫描结果缓存
└── cloud/thumbs/                      # 网盘缩略图缓存

数据库里有什么

表内容
assets照片与视频元数据：路径、拍摄时间、相机、地点、尺寸、大小、收藏、隐藏、查看时间等
albums / folders相簿、文件夹与层级关系、自定义封面、相簿内顺序
people本地人物聚类结果与人物关系
settings图库级设置：视图状态、系统图库连接、网盘挂载与收藏、智能助手配置与对话等
asset_analysis端侧场景标签、OCR 文字、归一化特征向量
asset_overlays官方「照片」图库的拾光补充元数据（收藏 / 隐藏 / 关键词 / 查看时间）

官方「照片」图库的只读边界

打开官方图库时，它就是这个 App 的当前图库。照片内容读取 Photos.sqlite，拾光自己的数据写在该库第一层的 database/PhotosClone.sqlite（与 Photos.sqlite 并列）。Apple 的数据库与自带原图始终只读。

不要手动搬数据库日志

迁移图库时，禁止直接复制 -wal / -shm：先把旧库三件套复制到临时目录，用 SQLite 执行 wal_checkpoint(TRUNCATE) 合并，再只移动主库文件。把别的库的日志放进当前库目录，会被当成当前库日志回放，覆盖现有数据。

备份与迁移

  • 退出应用后，整包复制 .photoslibrary 即为完整备份；恢复时放回任意位置并用「打开图库」选中它。
  • 外置磁盘未挂载时，拾光不会把「文件不存在」当成删除：元数据保留，缩略图显示占位。
  • 旧版放在 private/com.lijialong.photosclone/ 的数据会在启动或打开图库时自动上移到第一层，幂等且只移动一次。
  • 需要彻底重来：先备份整包，再删除图库包；应用不会在固定位置留下图片。

删除会清理什么

永久删除照片时会同步清理原图、缩略图、编辑渲染结果、压缩备份、视频转码缓存与端侧分析记录，并让内存中的缩略图缓存失效。移到「最近删除」只是标记，仍可在保留期内恢复。

04浏览

侧边栏决定「看哪个范围」，工具栏决定「怎么看」。所有范围共享同一套缩略图尺寸、排序与筛选，但只有图库层级提供年 / 月时间轴。

侧边栏

侧边栏固定三个分区，每个图库都是独立一套：

拾光

固定项目（个人收藏、最近保存、地图、视频、截屏、人物、最近删除等）、相簿、文件夹、智能相簿、媒体类型与更多项目。右键任意项目可固定或取消固定。

系统图库

可保存多个官方「照片」图库连接；同一时间只有一个处于连接/展开状态。连接列表跟着当前图库走，切换图库时整套更换。

网络存储

每个网盘一行；进入后浏览各自目录，能力与本地网格一致（受写入权限限制）。

分区标题在悬停时显示「更多」菜单与收起/展开按钮。相簿与文件夹默认收起，只记录你展开过的项目 —— 系统图库可能有上万个相簿。

时间轴：年 / 月 / 所有照片

  • 年：每年一张拼图卡片（最多 4 张照片），点击进入该年的月总览。
  • 月：按月分段，段内按天展示拼图卡片；点击回到所有照片并定位到当天。
  • 所有照片：普通缩略图网格。相簿、文件夹与智能项目也使用普通网格，不显示年 / 月分段。

超过 5,000 张时，年 / 月总览改用 SQL 分区，每个分区最多取 4 张样本，不遍历全库。

四种显示形式

形式适合说明
正方形快速扫图裁剪为等边网格，信息密度最高
完整宽高比看构图按原始比例分组排布，行高统一，每张下方居中显示文件名
瀑布流逛灵感等宽多列、每列高度自适应，竖图横图混排不留空洞；卡片更大、带常驻投影
列表核对元数据缩略图 + 文件名 + 拍摄日期 / 尺寸 / 大小

本地图库、系统图库与网盘共用同一个显示形式设置。缩略图尺寸范围 56–360，可用工具栏滑杆、⌘+ / ⌘- / ⌘0 或触控板捏合调整。

排序、筛选与搜索

  • 排序：拍摄 / 添加日期、标题、文件名、大小、类型、相机、地点、时长。
  • 筛选：全部 / 收藏 / 已编辑 / 照片 / 视频 / 截屏 / 我的 / 未加入相簿。
  • 搜索：文件名、标题、相机、地点、关键词、场景标签、图内文字与人物。支持中文自然语言组合，详见「端侧智能」。

选择与信息浮卡

  • 单击选择，⌘ 或 ⇧ 单击多选，拖拽框选，方向键移动。
  • 空格 / 回车 打开所选；⌘A 全选。
  • 悬停可显示可逐项开关的元数据浮层；工具栏「信息」打开浮动信息卡。
  • 信息卡可用方向键切换选中项并就地更新，拖动标题移动、拖动右下角调整大小、双击标题复位。
  • 网格底部居中显示当前范围的照片与视频总数；有选中项时让位给操作条。

查看器

查看器有两种形态，在设置 › 通用 › 浏览方式中切换，默认「窗口内浏览」：

窗口内浏览

保留侧边栏与顶部工具条：返回、缩放滑杆、日期与序号、信息 / 共享 / 收藏 / 幻灯片 / 编辑 / 更多。可边看边切换相簿。

全屏沉浸

查看器覆盖整个窗口并隐藏侧边栏，适合专注看图。照片带投影居中显示。

  • 开图渐进加载：先用网格缩略图与 1024px 中等层即时占位，全尺寸解码完成后平滑淡入。
  • 相邻照片会预取中等层与全尺寸层，连翻不闪白。
  • 查看器内可打开信息面板、编辑、收藏、幻灯片、共享，或用 L 播放实况照片。
  • 方向键翻页；空格收起查看器；+ / - / 0 或双击缩放。

大图库分页

本地图库超过 5,000 张且处于「所有照片」网格时，筛选、排序与计数下推到 SQLite，每页 600 张滚动加载。查看器单步翻页使用 keyset 相邻查询，连翻成本与照片总量无关。

仍需注意的范围

人物、回忆与地图基于内存索引；超百万张时首次进入这些页面会较慢。图库元数据在启动时整体载入内存，分页主要降低筛选、排序与复制的开销。

视频播放

  • 基于 AVPlayer；系统无法解码的编码可用可选的 ffmpeg 转码为 H.264 后播放。
  • 默认一个视频播完后自动连播下一个视频（跳过照片），也可改为循环当前视频。
  • 播放控制条可拖到画面任意位置，双击把手复位；点时长可切换剩余时间。
  • 支持填充 / 适应画面、上一个 / 下一个视频、倍速、音量、画中画、保存当前帧与全屏。

05组织

相簿、文件夹、智能相簿、人物、地图与体检，共同构成拾光的整理层。所有组织关系都写入当前图库，随图库一起移动。

相簿与文件夹

  • 支持多级文件夹与相簿：新建、重命名、删除、移动、拖拽加入。
  • 点侧边栏文件夹只展示它下一层的子文件夹与相簿（不是照片）；标题旁提供「返回上一级」。
  • 「所有相簿」只展示第一层；进入文件夹后逐层展示下一层。
  • 卡片大小随工具栏缩放（⌘+ / ⌘- / ⌘0）调整。
  • 把照片从网格拖到侧边栏相簿或「所有相簿」卡片即可加入；拖动时显示缩略图与数量徽标，目标高亮。
  • 在相簿网格里把照片拖到另一张照片的左 / 右半侧，可插入其前 / 后，顺序随相簿保存。

自定义相簿封面

在相簿里右键任意照片或视频，选择「设为相册封面」；右键相簿卡片或封面本身可「恢复自动封面」回到首张。封面随相簿持久化；移除该项目时自动回落。

智能相簿

按媒体类型、收藏、已编辑、关键词、相机、镜头、地点、定位、拍摄日期、像素、文件大小、文件名、时长、场景与图内文字自由组合条件。条件之间可选「满足全部」或「满足任一」，编辑时实时预览命中数量。

场景智能相簿

「场景」分区的「更多」菜单可把已识别的场景一键写成智能相簿；之后新分析的照片会自动落入对应相簿。

关键词

按 ⌘K 为所选项目添加关键词；侧边栏「更多项目 › 关键词」可集中管理，也可在搜索框直接输入关键词。

人物

  • 本地图库可用端侧人脸聚类在 Mac 上离线分析，按人脸相似度自动聚合为人物。
  • 支持重命名、查看某人的全部照片；人物页顶部列出「常一起出现」的组合，点开可看两人同框。
  • 照片移入最近删除或被隐藏后不再计入人物；永久删除时同步清理人物关系，没有可见照片的人物自动消失。
  • 系统「照片」图库直接读取官方已有的人物 / 宠物识别结果，不参与本地聚类。

重复项目与相似照片

重复项目按「文件大小 + 像素尺寸」分组，逐组展示；合并时按分辨率、文件大小与收藏挑出「最佳」一张。它与「相似照片」不同：前者处理完全重复，后者按图像特征找同场景 / 同构图。

图库体检

「图库体检」把模糊照片、相似连拍、过大视频与可腾出空间集中成一张清单。清晰度在缩略图上用拉普拉斯方差评估，不解码原图。

  • 体检结果只保存在内存（healthReport），不新增数据库表。
  • 相似组会保留每组最清晰的一张，其余可一键移入最近删除；不会自动删除。
  • 扫描可随时停止；再次体检会重新评估当前图库。

导入项目与最近删除

  • 导入按批次分组，每段显示「导入于 年/月/日 时:分」与该批项目数；批次 ID 随照片写入图库。
  • 最近删除默认保留 30 天，可在设置 › 图库中改为 7 / 30 / 90 / 180 天或永不自动清理。
  • 在「最近删除」中按 ⌘⌫ 会永久删除；其他位置按 ⌘⌫ 只是移入最近删除。

06端侧智能

场景识别、OCR 与图像特征全部由 Vision 在本机完成。分析结果写入当前图库的 asset_analysis 表，不联网、不上传，也不需要账号。

运行分析

  1. 侧边栏「场景」分区点「分析照片内容…」，或用「更多」菜单执行整库分析。
  2. 也可以在信息面板的「智能标签」中就地分析单张照片。
  3. 需要人物时，进入「人物」页运行本地人脸聚类。
  4. 分析完成后，「场景」「包含文字」与相似照片结果才会出现。
只作用于拾光本地图库

系统「照片」图库与网盘不参与端侧分析；视频暂不参与。首次分析需要逐张读取图片，照片越多耗时越长。

场景目录

场景按人物 / 动物 / 自然风景 / 食物 / 建筑 / 交通 / 室内 / 文档 / 夜景 / 活动聚合计数。点任一行查看该场景照片；「更多」菜单可把已识别场景生成智能相簿。

自然语言搜索

搜索框会解析时间词、类型限定、人物名字与场景词，其余词作为普通关键词匹配文件名、标题、相机与地点。中文口语词（如「海边」「烟花」）会映射到 Vision 的英文标签再匹配。

类型可用写法
相对时间今天、昨天、前天、本周、上周、本月、上个月、今年、去年、前年
绝对时间2024、2024年5月、2024-05、2024年5月20日、5月、5月20日
类型 / 状态收藏（喜欢 / 最爱）、视频、照片、截图（截屏）、实况、已编辑
人物直接输入人物名字（需已完成人物聚类）
场景 / 文字海边、烟花、日落、小猫、包含文字的内容等（需已完成分析）

示例：去年 海边 狗、2024年5月 日落、上个月 小猫、有文字的截图。多个时间词会取交集；只写月份且该月还没到时，理解为去年那个月。

OCR 图内文字

分析时识别照片中的中英文文字并落库。「更多项目 › 包含文字」列出所有含文字的照片；也可以直接在搜索框输入文字内容定位。

相似照片

右键任意已分析的照片「查找相似照片」，按特征向量余弦相似度找出同场景 / 同构图项目。结果在网格顶部显示提示条，可一键退出。

存储与隐私

  • 标签、OCR 文字与归一化特征向量写入 asset_analysis；内存索引只保留标签与文字，向量按需读取。
  • 特征向量不会放进 PhotoItem，也不会进入 JSON。
  • 删除照片时同步删除分析记录；分析过程没有任何网络请求。

07智能助手（可选云端）

智能助手是一个独立的可选功能：只有你配置了自己的模型 API Key 后才会联网。它可以问答、检索和整理当前图库；所有写操作都会先弹窗确认。

能做什么

  • 就当前范围提问：照片数量、时间分布、场景构成、某张照片的拍摄信息与端侧标签。
  • 总结与解释：总结选中的一组照片，或结合端侧 OCR 文字解释画面内容。
  • 找照片：用 search_photos 搜索整个当前图库，或按模型给出的关键词与筛选条件应用检索。
  • 整理图库：新建相簿、把照片加入相簿、收藏 / 取消收藏、添加关键词、选中照片。
  • 安全边界：每次修改前弹出确认；不支持删除、编辑原图、导入，也不会写入官方「照片」库的 Photos.sqlite。

配置步骤

  1. 打开「设置 › 智能助手」，选择提供商。
  2. 确认接口地址与模型；豆包需要填写控制台创建的推理接入点 ID（ep-...）。
  3. 粘贴该提供商的 API Key，点「保存」。
  4. 点「测试连接」确认网络与 Key 可用。
  5. 回到主界面，点工具栏 ✨ 或「照片 › 智能助手…」开始对话。

提供商默认接口 / 模型说明

发送了什么

  • 当前范围摘要：范围名称、项目数、筛选与搜索条件、选中数量。
  • 最多 40 张候选照片的元数据：文件名、拍摄时间、尺寸、收藏 / 编辑状态、关键词、地点、端侧场景标签与 OCR 文字。
  • 不发送文件路径、原图目录、图库数据库，也不会把整个图库序列化给模型。
  • 更大范围的检索通过模型给出的关键词与筛选条件，回到本地的搜索与分页管线完成。

图片理解（默认关闭）

默认只发文字与元数据。开启「发送压缩缩略图」后，才会把选中照片（没有选中时取当前范围前几张）压成长边约 1024 的 JPEG 发给模型，单次最多 6 张；原始 RAW、视频与云端照片不会发送。模型需要支持视觉输入，例如 glm-4v-flash、qwen-vl-plus 或 gpt-4o-mini。

存储与隐私

  • API Key 只存 macOS 钥匙串（service com.baymax.luma.ai），不写入图库数据库、UserDefaults、日志或对话内容。
  • 模型配置与对话记录保存在当前图库的 settings 中（ai_config / ai_conversation）；切换图库会切换到各自的对话。
  • 请求直接发往你选择的提供商，不经过拾光的任何服务器；关闭助手或清空对话不会影响照片。
  • 写操作由模型调用本地工具完成：先弹窗列出将要创建 / 修改的内容，确认后才通过 LibraryStore 落盘；取消则不会改动图库。
  • 官方「照片」图库作为当前图库时，只允许写拾光补充元数据（收藏 / 关键词），不允许新建相簿或编辑原图。
模型能力差异

不同提供商与模型的上下文长度、视觉支持与限流策略不同。若报「模型不支持图片输入」，关闭图片理解；若报额度或频率错误，请检查提供商控制台。

08回忆与旅行

拾光会把数量足够的主题自动整理成回忆，也能从定位与时间中识别旅行，把一段行程播成影片。

精选集与回忆卡片

  • 精选集顶部按「按月」「按地点」「收藏」「那年今日」自动生成回忆卡片，只收录数量足够的主题。
  • 「那年今日」按年份（最多最近 3 年）各生成一条，以大横幅置顶。
  • 点击卡片进入回忆影片：均匀取样的照片按 Ken Burns 缓慢缩放平移播放。
  • 支持上一张 / 下一张、暂停与 Esc 退出。

风格与导出

回忆影片提供「经典 / 电影 / 清新」三种风格模板，电影风格带上下黑边。可以导出为 mp4：1280×720、24fps、照片间交叉淡化、无声。

影片是无声的

当前版本不包含配乐，也不支持在导出时剪辑片段。需要带音乐的成片时，请把 mp4 导入其他剪辑工具继续制作。

旅行

  • 按「拍摄时间 + 定位」自动识别出行：时间间隔过大或移动距离过远即切分。
  • 生成「杭州之行」这类旅行卡片，显示日期范围、天数与项目数。
  • 点击卡片打开故事线：首图拼贴 + 按天分组的照片。
  • 可一键「播放回忆」，把整段旅行转成电影风格影片。

09地图与足迹

带定位的照片会出现在地图页。地图右上角可切换「网格」，把地点与日期整理成可浏览的行程段。

地图浏览

  • 地图用坐标图钉标注拍摄点，可拖动平移、滚轮缩放。
  • 支持切换卫星底图，选择会被记住；重新进入地图页默认回到地图底图。
  • 信息面板中的地图与地点分级同样来自照片 EXIF 坐标。

地图网格

按「地点 + 连续日期」把带定位的照片切成行程段。段头显示城市、日期范围、张数与「查看地点」入口，下面是跟随缩放的照片卡片墙；换城市或隔天自动分段。

「网格」是一次性浏览方式；重新进入地图页会回到默认地图底图。

足迹回放

按拍摄时间顺序在地图上逐站点亮，把一段时间内的行程播成一条线。最多保留 180 个站点（按时间均匀取样），支持播放 / 暂停与调速；按 Esc 退出。

地点统计

按城市与地点统计照片数量，查看你把时间留在了哪里；点任一行可进入对应照片。

10编辑与输出

编辑是非破坏的：原图始终保留，渲染结果另存，编辑配方随图库保存，随时可以重新调整。

编辑器

支持旋转、水平 / 垂直翻转、裁剪与比例、滤镜、曝光、亮度、对比度、饱和度、高光、阴影、色温、色调、锐化、暗角、降噪与自动增强。

  • 保存后生成新的渲染结果，网格与查看器立即使用；cacheKey 含编辑版本，旧缓存自动失效。
  • 可按 ⌥⌘C 复制编辑点，⌥⌘V 粘贴到其他照片；编辑器内也有按钮。
  • 批量更改（⌥⌘B）可一次修改所选项目的标题、拍摄日期与地点。

RAW 与实况照片

  • 支持 DNG、CR2、CR3、NEF、ARW、RAF、ORF、RW2 等 RAW 格式导入。
  • 缩略图、查看器与编辑器统一走 CIRAWFilter（开启高光恢复），失败时回退 ImageIO。
  • 导入时自动把同名 MOV 识别为实况照片的配对视频；查看器内点「实况」或按 L 播放。
  • 导出、复制、删除都会带上配对视频。

导入

  • 入口：拖拽、文件面板（⌘I）、剪贴板粘贴、从系统「照片」导入（⌥⌘I）。
  • 导入始终把原文件拷贝进图库，不支持「引用原位置」。
  • 导入窗口支持按文件夹生成相簿、保留上层结构与进度显示，可取消。
  • 批量导入按 CPU 核数并发（上限 6），过程中增量写入新照片，结束或取消时再同步相簿与文件夹关系。

11系统「照片」图库

官方「照片」图库可以直接作为拾光的当前图库。内容只读解析，拾光的补充元数据写在 sidecar，不修改 Apple 的数据库与文件。

作为当前图库打开

  • 主侧边栏直接展示该库自己的结构：共享、媒体类型、更多项目、所有项目与相簿；不再显示「拾光 / 系统图库」两个分区。
  • 照片内容读取 Photos.sqlite，包括自定义标题、实况照片与连拍标记。
  • 收藏、隐藏、关键词与查看时间写入该库 database/PhotosClone.sqlite 的 asset_overlays，NULL 表示沿用 Apple 的值。
  • 删除、编辑、导入、重命名仍然禁止；相关菜单项为禁用状态。

多个连接（只读浏览）

侧边栏「系统图库」可保存多个图库连接，同一时间只有一个处于连接 / 展开状态。每个连接有独立菜单：在「照片」中打开、重新读取、在访达中显示、断开连接。连接新图库不会移除已有连接。

连接列表是 per-library 数据

列表与当前连接保存在当前图库自己的 settings.system_libraries。打开 A 图库只看到 A 的连接，切到 B 图库换回 B 的列表。旧的全局列表只作为一次性迁入来源。

扫描、缓存与载入上限

  • 扫描结果（索引与元数据，不含原图）缓存在当前图库的 resources/system-cache/，缩略图在 resources/system-thumbs/；签名取 Photos.sqlite 的大小 + 修改时间，切换图库不会共用缓存。
  • 缓存命中直接展示；签名变化才后台重扫。缩略图缓存写在当前图库包内，原图直接从官方库读取。
  • 超大图库按设置 › 通用 › 系统图库载入 › 载入上限从新到旧截断（5 万 / 10 万 / 20 万 / 不限制，默认 10 万），超出时提示真实总数。
  • 相簿与文件夹按 ZGENERICALBUM.Z_PK 排序并混排，与官方「照片」一致；默认全部收起。

拷贝到拾光

  • 支持多选照片、单张右键拷贝，或把某个相簿 / 文件夹（含子文件夹）整体拷贝到拾光。
  • 目录递归使用 systemFolderAssetIDs；重复项目按「同名 + 同大小」跳过。
  • 拷贝是唯一写入出口；不会在原库中创建拾光的文件。
iCloud 照片可能未下载到本地

如果官方图库开启了「优化 Mac 存储空间」，部分原图可能仍在 iCloud。拾光读取的是本地文件；需要完整离线副本时，先在系统「照片」中下载原片。

12网络存储

网络存储让 NAS 与云盘直接出现在侧边栏，不必先整库导入。所有凭据只存钥匙串，收藏只记录在本机。

接入入口

侧边栏「网络存储 › ＋」或菜单「文件 › 接入网络存储…」，打开同一个接入向导。选择 SMB、WebDAV、阿里云盘、百度网盘或 AList / OpenList。

SMB 共享

  • 适用于群晖、TrueNAS、Windows 共享等；地址形如 smb://主机/共享名。
  • 通过系统 NetFS 挂载（与 Finder「连接服务器」一致），挂载点由系统决定（/Volumes/<共享名>），拾光复用该挂载点读取。
  • 只读：不支持上传、重命名与删除。支持「在访达中显示」与用系统应用打开。
  • 打开应用时自动重连已保存的 SMB；断开时自动卸载。
  • 向导通过 Bonjour 自动发现局域网设备；共享列表通过系统 smbutil view 获取，密码只经伪终端写入。
  • 新添加的 SMB 默认点开即递归扫描「整个共享」，也可在浏览页切换为「按文件夹」。

WebDAV

  • 可浏览、播放，并支持新建文件夹、重命名、上传与删除。
  • 请求统一走 WebDAVClient，已处理百分号编码、Basic Auth、PROPFIND / MKCOL / PUT / MOVE / DELETE 与 Range。
  • 缩略图优先服务端缩略图；没有时用 Range: bytes=0-262143 读取文件头解析内嵌缩略图，绝不整文件下载。

阿里云盘 / 百度网盘 / AList

  • 阿里云盘与百度网盘使用 OAuth 2.0 桌面端授权，本地回环 127.0.0.1:53682/callback 接收 code，并校验 state。
  • Token 存钥匙串，过期由 CloudService.accessToken(for:) 自动刷新并回写。
  • 两者均为只读：可浏览、播放、幻灯片、打印与导出；不能上传或删除。
  • AList / OpenList 向导填写地址后自动推导 WebDAV 入口。

权限矩阵

范围读取改元数据 / 删除 / 编辑上传 / 重命名 / 新建文件夹
本地图库可以可以可以
官方「照片」图库作为当前图库可以仅补充元数据不可以
官方图库作为额外连接可以不可以不可以
WebDAV可以不可以可以
SMB 共享可以不可以不可以
阿里云盘 / 百度网盘可以不可以不可以

网络与安全

  • 网盘密码、OAuth 凭据与 token 只存 macOS 钥匙串（service com.baymax.photosclone.oauth；旧版条目会自动迁移）。
  • 凭据禁止写入 UserDefaults、日志或 CloudMount；SMB 密码不会进入 argv / 环境变量。
  • 网盘请求失败会转换为可读中文错误，不直接抛英文 NSError 文案。
  • 并发加载由 CloudConcurrencyGate(limit: 3) 控制，避免一次打满 NAS。
  • 云照片的「收藏」只写入当前图库的 settings（cloud_favorites），键为 mountID|path，不会写回服务器。

15数据与隐私

隐私在这个应用里是架构，而不是一句承诺：没有账号、没有遥测与第三方 SDK。端侧智能默认完全离线；可选的智能助手只有在你配置 API Key 后才会调用你选择的模型。

照片默认不上传

端侧场景、OCR 与特征向量由系统 Vision 在本机计算，断网也能完成分析与搜索。智能助手默认只发送元数据与端侧标签；图片理解必须显式开启。

数据库在图库里

元数据只有一份真源：图库内的 PhotosClone.sqlite。没有隐藏的云同步或影子数据库。

凭据在钥匙串

SMB / WebDAV 密码、OAuth 应用凭据、token 与智能助手 API Key 只存 macOS 钥匙串，绝不进入日志或设置文件。

写操作有边界

官方「照片」图库、SMB、阿里云盘与百度网盘没有写入路径；智能助手的修改操作会先弹窗确认，且不支持删除或编辑原图。

网络访问清单

  • 端侧分析与本地浏览不需要网络；应用不会在后台发起分析或统计请求。
  • 仅当你主动接入网络存储时，应用才会向对应主机发起连接。
  • WebDAV / SMB / 云盘请求用于列目录、取缩略图、播放与（WebDAV）上传；没有分析或统计请求。
  • 智能助手只在你发送消息时，直接连接你所选提供商的接口；发送内容与图片策略见「07 智能助手」。拾光没有中转服务器。
  • 应用不包含自动更新器，也不会在后台下载内容。

16常见问题

可以在不建库的情况下先看看吗？

不能。没有图库时主界面会被建库门禁挡住，避免在固定位置创建散落数据。先新建一个图库，或打开已有的 .photoslibrary。

为什么照片文件不见了，但记录还在？

外置盘未挂载或文件暂时不可达时，拾光不会把空结果写回数据库。缩略图会显示占位，重新挂载磁盘后即可恢复。请不要在这种情况下执行「清理」类操作。

可以在一个窗口里同时看两个图库吗？

当前只能有一个图库作为「当前图库」。其他官方「照片」图库可以在「系统图库」分区作为只读连接保存，随时展开浏览，但同一时间只有一个连接处于活动状态。

为什么首次分析很慢？

场景、OCR 与特征向量都要逐张读取图片并在本机推理。照片越多耗时越长，但结果只需计算一次；之后搜索与相似检索都走本地数据库。

为什么相似照片不会自动删除？

删除是不可逆的产品决策，必须由你确认。体检与相似检索只给建议；执行删除时会移入最近删除，保留期内仍可恢复。

视频无法播放怎么办？

先确认系统播放器能否打开。某些编码需要可选的 ffmpeg；安装并确保它在 PATH 中，拾光会转码为 H.264 后播放。

为什么不能编辑官方「照片」图库里的照片？

为了不破坏 Apple 的数据库与原图，官方图库只允许写入拾光的补充元数据（收藏 / 隐藏 / 关键词 / 查看时间）。需要编辑时，把照片拷贝到拾光图库后再改。

图库可以放在 NAS 上吗？

可以通过系统挂载的卷使用，但不要把正在使用的图库放在不稳定的网络卷上。断线会导致读写失败，甚至让 SQLite 处于不一致状态。更稳妥的做法是图库放在本地或直连磁盘，NAS 通过「网络存储」浏览。

怎么彻底卸载？

退出应用，删除 Luma.app；如不再需要，可删除图库包与 ~/Library/Application Support/PhotosClone/。应用不写系统级后台服务。

17已知限制

以下限制是当前版本的真实边界，购买或迁移前请先确认。

  • 官方「照片」图库、SMB 共享与阿里云盘 / 百度网盘为只读；只有本地图库与 WebDAV 支持写入。
  • 暂未实现：视频修剪与慢动作变速、iCloud 共享图库、屏幕保护输出。
  • 回忆影片导出为无声 mp4（不含配乐）。
  • 端侧人脸聚类只在本地图库生效，需要逐张分析，首次运行较慢；系统图库只读官方已有人物结果。
  • 场景标签、OCR 与相似照片同样只对本地图库照片生效，视频不参与；未分析的照片不会出现在结果里。
  • 智能助手每次只带当前范围最多 40 张候选照片；更大范围检索通过「应用筛选」回到本地搜索管线。视觉支持、上下文长度与限流取决于所选提供商与模型。
  • 导入始终拷贝原文件，不支持引用原位置。
  • 视频转码依赖外部 ffmpeg；未安装时仅支持系统可解码的编码。
  • 「年 / 月」时间轴总览只在图库层级提供；相簿 / 文件夹使用普通网格。
  • 大图库分页覆盖「所有照片」与媒体类型 / 收藏 / 隐藏等本地范围；人物、回忆与地图仍基于内存索引，超百万张时首次进入较慢。
  • 图库元数据仍在启动时整体载入内存；分页主要减少筛选 / 排序 / 复制的开销。
  • HDR 设置对查看器内的静态图片生效；系统级 EDR 行为仍由 macOS 决定。
  • SMB 的「整个共享」扫描在超大目录上首次会较慢，之后刷新会重新读取。

选拾光，如果你……

照片在本地或 NAS、图库很大、需要批量整理与可检查的本地索引；愿意用文件系统与键盘工作。
